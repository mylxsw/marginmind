# 三期阅读增强：界面规格

> 建立日期：2026-10-28（GUL-548）。上位文档：[`phase-3-reading.md`](phase-3-reading.md)（第 3.4 节空间规则、第 4 节数据模型、第 8 节已定决定、第 9 节文案原则）。
> 交互目标：原型 [`design/prototype/phase-3-reading.html`](../design/prototype/phase-3-reading.html)（演示控制台前 9 个场景），已按本文第 6 节同步。
> 视觉以 macOS 原生质感和 `mm_design` 令牌为准，原型的 CSS 数值只作参考；工具栏、浮动工具条、脑图交互以现有应用为准。

本文写给实现者：每个组件给出尺寸（pt）、令牌、状态、键盘和动效。没有写到的细节沿用 [`design-system.md`](design-system.md) 和 [`phase-3-assistant-ui.md`](phase-3-assistant-ui.md) 第 0 节。
“批次”列对应上位文档第 6 节（A 裁边 / B 页边批注 / C 对照阅读 / D AI 逐段对照）。

**页面坐标与屏幕尺寸。** 下文标“页面 pt”的数值属于 PDF 页面坐标，随缩放变化（裁边框、页边列宽、锚点位置）；其余都是屏幕 pt，不随缩放变化（字号、卡片内边距、标记、浮层）。

## 0. 通用约定

### 0.1 令牌

| 用途 | 令牌 |
| --- | --- |
| 选中态、手柄、主按钮、对照段落高亮 | `accent` / `accentTint`；段落高亮用 `accent` 9% |
| 批注卡底色、色条 | 批注颜色 `MMAnnotationColor`（六色，存 `colorIndex`）；底色见 0.2 |
| 批注锚点虚线、连线、刻度、页边标记 | 新增 `MMReaderStyle.marginNoteLine`、`marginNoteMarker`（0.2） |
| 浮层（页面菜单、对照菜单、标记弹层、批注“…”菜单） | `MMGlass` + `glassShadow`，圆角 14，与现有菜单一致 |
| 胶囊（裁边提示、调整裁边工具条） | `MMGlass`，0.5pt `hairline`，圆角 = 高度 / 2 |
| 正文 / 次要文字 / 图标 | `label` / `secondaryLabel` / `icon` |
| 提醒（标注将被隐藏） | `caution`，底为自身 15% |
| 失败（翻译失败） | `critical`，底为自身 10% |
| 分隔线 | `separator`；对照标题条与栏缝用 0.5pt |

| 字号 | 令牌 |
| --- | --- |
| 批注卡正文、标记弹层正文 | `body` 的 12 号（`body.copyWith(fontSize: 12, height: 1.55)`） |
| 菜单项、按钮、标题条 | `callout`（12 / 500）；标题条文档名 600 |
| 计数徽标、语言标签、裁边页标签、“+ 写批注” | `footnote`（11）；徽标与语言标签 10 / 600，数字用 `tabularFigures` |
| AI 译文正文 | `readingBody`（与原文同字号；用宋体系） |

间距只用 `MMSpacing`（2 / 4 / 8 / 12 / 16 / 20 / 28）。下文出现的 5、6、9、10 等非刻度值是为了和 PDF 页面对齐，只用在本文列出的位置。

### 0.2 阅读配色下的页边

页边列和批注卡画在页面旁边，跟随阅读配色（`MMReaderStyle`），不跟随应用的浅色 / 深色外观。浮层、工具条、标题条跟随应用外观。在 `reader_style.dart` 增加：

| 成员 | 白 / 纸 / 绿 | 黑暗 |
| --- | --- | --- |
| `marginFill` 页边列底色 | `paperColor` | `paperColor` |
| `marginNoteFill(MMAnnotationColor c)` 卡片底色 | `Color.alphaBlend(c.color 16%, paperColor)` | `Color(0xFF2A2A2C)`（所有颜色相同，只靠色条区分） |
| `marginNoteText` 卡片文字 | `Color(0xFF3A3A3C)` | `Color(0xFFE5E5EA)` |
| `marginNoteLine` 锚点虚线、连线、刻度 | `Color(0x8CC27C0E)` | `Color(0x80FFCC00)` |
| `marginNoteMarker` 页边标记底色 | `Color(0xFFFFD60A)` | `Color(0xFFFFD60A)` |
| `marginGuide` 页边列左侧虚线 | `Color(0x21000000)` | `Color(0x24FFFFFF)` |

卡片色条用 `c.color`（不透明），所有配色相同。标记文字固定 `Color(0xFF3A3A3C)`（底色是亮黄）。

### 0.3 动效

| 动作 | 时长 / 曲线 |
| --- | --- |
| 悬停、按下、颜色、连线高亮 | `MMMotion.quick` + `quickCurve` |
| 卡片排布下移（`top` 变化） | `MMMotion.standard` + `layoutCurve` |
| 裁边开关（页面宽度）、页边列出现 | `MMMotion.layout` + `layoutCurve`；页边列淡入 |
| 页边标记出现 | 缩放 0.6 → 1，`MMMotion.standard` + `Curves.easeOutBack` |
| 浮层、提示胶囊出现 | 现有浮层动效（淡入 + 上移 4） |
| AI 译文占位条 | 横向微光，1.2s 循环 |
| 译文到达 | 淡入 360ms |
| 跳到锚点 / 脑图节点 | `MMMotion.flash`，复用现有高亮闪烁 |

“减弱动态效果”（`MMAppearance.reduceMotionOf`）打开时：裁边、页边列、卡片下移直接到位；标记不缩放；占位条改为静态 `quaternaryFill`；译文直接出现。

### 0.4 图标

需要新增到 `MMIcons`（都是 Cupertino 已有的图标）：

| 名称 | CupertinoIcons | 用途 |
| --- | --- | --- |
| `crop` | `crop` | 裁边提示、调整裁边工具条、页面菜单 |
| `marginNote` | `text_bubble` | 工具栏“页边批注”、浮动工具条“批注”、页边标记 |
| `compare` | `square_split_2x1` | 工具栏“对照阅读” |
| `swapSides` | `arrow_right_arrow_left` | 对照标题条“左右互换” |
| `alignHere` | `equal` | 栏缝“对齐此处” |

沿用：同步滚动 `link`、页面菜单按钮 `pageZoom`（不换图标）、加入脑图 `mindMap`、在脑图中定位 `revealSource`、更多 `more`、关闭 `close`、警告 `warning`、完成 `check`、AI 翻译 `translate`、导入 `add`、文档 `document`。

### 0.5 文案

遵守上位文档第 9 节：组件里不放副标题、说明行、占位提示、尺寸读数。图标按钮必须有 tooltip（无障碍需要），tooltip 只写名称和快捷键（`AppShortcuts.tip`）。开关类按钮用选中态表示开关，tooltip 不写“开 / 关”。
只保留缺了用户就会做错事的文字：AI 不可用的原因、“N 处标注将被隐藏”、HUD 的结果和一个动作。全部文案见第 4 节。

## 1. 入口与菜单

### 1.1 原文栏工具栏（`reader_pane.dart` 的 `_toolbar`）

**常规尺寸（桌面全部窗口；`MMSizeClass.regular`）**，从左到右，`Wrap` 不变：

| 顺序 | 控件 | 变化 |
| --- | --- | --- |
| 1 | 页面侧栏 | 不变 |
| 2–3 | 缩小 / 放大 | 不变 |
| 4 | **页面菜单**（原“页面适配”，`ValueKey('reader-zoom')` 改为 `reader-page`） | 图标仍是 `pageZoom`；tooltip “页面”；当前文档已裁边时为选中态（`selected`，`accent` 色）。菜单见 1.2 |
| 5 | 阅读外观 | 不变 |
| 6 | 标注工具（`ReaderAnnotationTools`，含原文与脑图联动） | 不变 |
| 7 | **页边批注**（批次 B，`ValueKey('reader-margin')`） | `MMToolbarButton`，图标 `marginNote`，右侧计数徽标（当前文档批注数，0 时不显示）。页边展开时选中态。tooltip “页边批注（⌥⌘M）”。对照阅读时禁用（批注一律以标记显示） |
| 8 | **对照阅读**（批次 C，`ValueKey('reader-compare')`） | `MMToolbarButton`，图标 `compare`，对照模式时选中态，tooltip “对照阅读”。点开对照菜单（1.3） |
| 9 | OCR 进度 | 不变，仍在最后 |

7、8 两个按钮之间间距与标注工具组内一致（`MMSpacing.xs`），和 6 之间留一个组间距（`MMSpacing.s`）。徽标：`footnote` 10 / 600，`tabularFigures`，紧贴图标右侧（左间距 2），颜色跟随按钮前景色；按钮宽度随徽标增长，不截断。

**窄窗口。** 桌面窗口最小 960 宽，常规尺寸里工具栏按 `Wrap` 换行：7、8 排在 6 之后、OCR 进度之前，所以最先换到第二行，不进“更多”。
**触屏窄尺寸（`compact` / `medium`）**：

| 尺寸 | 一行显示 | 收进“更多”（`reader-more`），自上而下 |
| --- | --- | --- |
| `medium`（iPad 竖屏、分屏） | 页面侧栏、标注工具、页边批注、对照阅读、更多、OCR 进度 | 缩小、放大 ｜ 实际大小、适合宽度、适合页面 ｜ ✓ 裁掉白边、调整裁边… ｜ 四种阅读配色 |
| `compact`（手机） | 页面侧栏、标注工具、更多、OCR 进度 | 同上。页边批注和对照阅读不出现：手机上页边永远放不下（批注一律以标记显示），也放不下两栏 |

`medium` 下原文栏宽度不足 874（`2 × MMSizes.readerMinWidth + 34`）且收起侧栏和脑图后仍不足时，对照菜单里的文档项和 AI 项禁用，第二行显示“窗口太窄”（1.3）。

### 1.2 页面菜单（批次 A）

`PopupMenuButton` 的菜单，宽 232。每项左侧 14 宽的勾选列（`check` 12，`accent`），只有当前项显示。

```text
  实际大小
✓ 适合宽度
  适合页面
──────────────
✓ 裁掉白边          ⌥⌘K
  调整裁边…
```

- 前三项沿用 `ReaderZoomCommand`，勾选当前适配方式；手动缩放后三项都不勾。
- “裁掉白边”是开关，勾选表示当前文档已裁边。当前文档自动裁边框四边合计不足 8 页面 pt、且没有手动裁边时禁用（裁了也看不出差别）。
- “调整裁边…”进入调整模式（2.2）。调整模式中整个菜单禁用。
- 快捷键列 `footnote`、`secondaryLabel`，与现有菜单一致。

### 1.3 对照菜单（批次 C、D）

宽 340，从工具栏按钮下方弹出；右栏标题条的文档名（2.6）弹出同一个菜单。

```text
  [文档图标] Cognitive Science Primer.pdf   [推荐]   EN
  [文档图标] 第 3 章讲义（扫描版）.pdf                 中
  [+]        导入 PDF…
──────────────
  [翻译]     AI 逐段翻译成中文
             先配置模型                       ← 只在不可用时出现
──────────────                                ← 只在对照模式时出现
  [×]        退出对照阅读                     Esc
```

| 项 | 规格 |
| --- | --- |
| 文档项 | 高 30（最小），内边距 5×9。图标 14（`document`，扫描版同图标）+ 文件名（`callout`，单行省略）+ 可选 `MMPill`“推荐”+ 语言标签（`footnote` 11、`secondaryLabel`，“中”/“EN”，未知语言不显示）。另一语言版本排在最前且标“推荐”，其余按学习集顺序。当前右栏文档显示选中态 |
| 导入 PDF… | 沿用 `importPdf`。先加入学习集，再在右栏打开 |
| AI 项 | 图标 `translate` + “AI 逐段翻译成{语言}”。目标语言 = 当前文档语言的另一种（中 ↔ English），语言未知时跟随应用的翻译语言设置。平台不支持助手（`MMPlatformCapabilities.current.assistant == false`）时整项不出现 |
| AI 项不可用 | 50% 透明、不可点，名称下方一行原因（`footnote` 11、`secondaryLabel`）：未配置模型“先配置模型”；断网且当前模型不是本机模型“断网”；扫描版未识别“先识别文字”。同时满足多个时按此顺序只显示第一个 |
| 窗口太窄（仅触屏 `medium`） | 文档项和 AI 项都禁用，菜单第一项上方一行“窗口太窄”（`footnote`、`secondaryLabel`，内边距 6×9）。不另做提示 |
| 退出对照阅读 | 仅对照模式时出现，快捷键列显示 `Esc` |
| 学习集只有一份文档 | 只有“导入 PDF…”和 AI 项 |

### 1.4 浮动工具条“批注”（批次 B，`selection_toolbar.dart`）

| 项 | 规格 |
| --- | --- |
| 位置 | 颜色与分隔线之后的第一个按钮（选区为“高亮”，已有高亮为“加入脑图 / 定位卡片”）**之后**、“拷贝”之前 |
| 样式 | `MMToolbarButton`，图标 `marginNote`，`ValueKey('selection-margin-note')`，tooltip “批注（C）” |
| 出现条件 | 文字选区、已有高亮、框选区域都出现（框选的锚点是框选矩形，没有引文）。AI 译文栏的选区**不出现**（批注只写在原文上） |
| 已有批注的锚点 | 点“批注”不新建，直接进入那条批注的编辑 |
| 快捷键 | `readerSelectionShortcuts` 增加 `SingleActivator(LogicalKeyboardKey.keyC)` → `ReaderSelectionCommand.marginNote`（⌘C 仍是拷贝） |

### 1.5 菜单栏“显示”菜单（`app_commands.dart`）

加在 `view` 列表“页面侧栏”分组之后、阅读配色之前，`inWorkspace && hasDocument` 时出现：

| 菜单项 | 快捷键 | 启用条件 |
| --- | --- | --- |
| 裁掉白边 / 取消裁边（按当前状态切换文字，与“显示 / 隐藏助手”写法一致） | `AppShortcuts.toggleCrop`：`primaryShortcut(keyK, alt: true)`（⌥⌘K；非 macOS 为 Ctrl+Alt+K） | 有文档、不在调整模式、页面菜单里该项可用 |
| 调整裁边… | 无 | 有文档、不在调整模式 |
| 显示页边批注 / 隐藏页边批注 | `AppShortcuts.toggleMarginNotes`：`primaryShortcut(keyM, alt: true)`（⌥⌘M；非 macOS 为 Ctrl+Alt+M） | 有文档、不在对照模式 |
| 退出对照阅读 | 无（Esc 只在阅读区内生效，不放进菜单，避免抢走其他 Esc） | 对照模式 |

两个新快捷键已确认不冲突：⌥⌘K、⌥⌘M 在 `AppShortcuts` 里未使用（⇧⌘M 是画笔、⌥⌘N 是添加笔记）。菜单栏的快捷键在文本框有焦点时照常交给文本框（沿用 `_textFocused` 判断）。

### 1.6 快捷键汇总

| 键 | 作用 | 生效范围 |
| --- | --- | --- |
| C | 写批注 | 浮动工具条显示时（`readerSelectionShortcuts`） |
| ⌥⌘M | 页边批注 展开 / 收成标记 | 全局（菜单栏） |
| ⌥⌘K | 裁掉白边 开 / 关 | 全局（菜单栏） |
| ↩ / Esc | 调整裁边：完成 / 取消 | 调整模式 |
| ⌘↩ / Esc | 批注编辑：保存 | 批注输入框 |
| Esc | 退出对照阅读 | 阅读区有焦点、没有浮层 / 浮动工具条 / 编辑中的批注、当前工具是“选择” |

Esc 顺序（阅读区）：关闭浮层 → 关闭浮动工具条 → 保存正在编辑的批注 → 取消调整裁边 → 退出对照阅读。

## 2. 组件

### 2.1 裁边提示 `CropSuggestion`（批次 A）

| 项 | 规格 |
| --- | --- |
| 出现条件 | 当前文档左右空白合计 > 100 页面 pt（按自动裁边框），未裁边，不在调整模式，这份文档没点过 ×、没用过裁边；布局不是“仅脑图”。对照模式下左右栏各自判断，提示放在对应栏 |
| 位置 | 原文栏（或对照栏）内容区顶部居中，距离工具栏下沿 8；对照模式在标题条下方 8。浮在页面之上，不占布局 |
| 容器 | 高 38、圆角 19，`MMGlass`，内边距左 12、右 4，元素间距 8 |
| 内容 | 图标 `crop` 14（`accent`）→ `MMButton.primary`“裁掉白边”→ `MMIconButton`（24 / 图标 11）`close`，tooltip“关闭” |
| 点“裁掉白边” | 开启裁边（同 ⌥⌘K），提示消失；HUD 见 2.8 |
| 点 × | 提示消失，这份文档不再提示（存在 `DocumentCrop` 旁的文档级标记里，跨设备同步） |
| 不出现的情况 | 已裁边、提示已关、裁边框不足 100 pt、扫描页还没算完裁边框（算完后再出现，不闪烁） |

### 2.2 调整裁边 `CropEditor`（批次 A）

进入：页面菜单“调整裁边…”或菜单栏。工具切回“选择”，浮动工具条关闭，页面临时改为**整页适配**（宽高都放得下，显示完整页面），批注收成标记。退出后恢复进入前的缩放和阅读位置。

**工具条**（浮在原文栏内容区顶部居中，距工具栏下沿 10）：

| 项 | 规格 |
| --- | --- |
| 容器 | 高 40、圆角 20，`MMGlass`，内边距左 12、右 5，元素间距 6；分组之间 `MMToolbarDivider` |
| 内容 | 图标 `crop` 14（`icon` 色）｜ `MMSegmentedControl`：所有页 / 奇偶页分开 / 仅本页 ｜ `MMButton.secondary`“自动”“不裁”｜ `MMButton.secondary`“取消”+ `MMButton.primary`“完成” |
| 所有页 | 一个裁边框作用于所有页；切到这里时清除奇偶和单页设置 |
| 奇偶页分开 | 偶数页用 `all`，奇数页用 `odd`（第一次切换时从 `all` 复制） |
| 仅本页 | 拖动只改当前页（`pages[n]`，第一次拖动时从当前生效的框复制） |
| 自动 | 重新计算自动裁边框，范围回到“所有页” |
| 不裁 | 四边归零，范围回到“所有页”；此时“完成”等于关闭裁边 |
| 完成（↩） | 应用并退出，一个撤销步骤（⌘Z 回到进入前） |
| 取消（Esc） | 恢复进入前的裁边设置并退出 |

**每页的叠层：**

| 项 | 规格 |
| --- | --- |
| 裁掉的区域 | 黑色 34% 遮罩（四块矩形），不随阅读配色变化 |
| 裁边框 | 1.5pt `accent` 描边，画在框内侧 |
| 手柄 | 四边中点各一个。可见部分：上下边 28×6、左右边 6×28，圆角 3，白色 + 1.5pt `accent` 描边 + 阴影（`0 1 3 rgba(0,0,0,.3)`）。命中区：上下边 44×22、左右边 22×44。光标：上下 `resizeUpDown`、左右 `resizeLeftRight` |
| 拖动 | 按页面坐标计算，取整到 1 页面 pt；裁后至少保留宽 160、高 200 页面 pt；拖动中实时更新本页（范围是所有页 / 奇偶页时，同组的其他页一起更新） |

## 5. 验收要点（给各批次的 widget 测试）

- 工具栏：页面菜单 key `reader-page`、已裁边时选中；页边按钮徽标数随批注增删；对照模式下页边按钮禁用；触屏 `compact` 不出现页边和对照按钮，“更多”里有裁边两项。
- 裁边：提示的出现条件与 × 后不再出现；⌥⌘K 开关与 HUD 撤销；调整模式整页适配、范围三选一、自动 / 不裁、↩ 完成一步撤销、Esc 还原；“N 处标注将被隐藏”数量；阅读位置保持。
- 页边批注：C 新建并聚焦、空批注离开即消失（无 HUD）、清空 = 删除（HUD 撤销）；页边空白点击新建 `lineY` 批注；排布不重叠（间距 8）；< 78% 收成标记、弹层按钮三种情况；加入脑图两种布局的 HUD；修改同步到脑图卡片。
- 对照阅读：进入收起侧栏 / 脑图（< 900）、退出恢复；同步滚动防回环；对齐此处 HUD 撤销；互换；Esc 顺序；AI 项三种不可用原因与平台无助手时隐藏；AI 栏选区无“批注”。
- AI 译文：占位条保持高度、逐段替换、翻译中计数、已保存、失败重试；悬停段落双栏高亮。
- 配色：四种阅读配色 × 浅 / 深外观下页边列与卡片颜色取自 `MMReaderStyle` 新成员（单测）。
- 文案：第 4.4 节列出的文字在界面上不存在（测试里断言）。
