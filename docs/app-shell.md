# 应用框架：窗口、面板与命令

本文说明主界面的结构，以及面板如何展开、收起、切换和搜索。设计依据见 `design/canvas/Library.dc.html`、`Main.dc.html` 与 `Components.dc.html`。

## 窗口骨架

每个界面都由 `MMWindowScaffold` 组成：

```
┌──────────┬─────────────────────────────────────────────┐
│ ● ● ●  ⊟ │ 标题 / 副标题           [胶囊] [胶囊] [搜索] │  ← MMToolbar（56）
│          ├─────────────────────────────────────────────┤
│  侧栏     │                                             │
│ (悬浮玻璃) │                  内容区                     │
│  236      │                                             │
└──────────┴─────────────────────────────────────────────┘
```

- macOS 上标题栏透明、内容铺满窗口，系统红绿灯被移到侧栏顶部（`DesktopWindow.initialize`）。
- 工具栏和侧栏顶部的空白处可以拖动窗口，双击则缩放窗口。
- 侧栏收起时以 320ms 的动画滑出；工具栏左侧自动留出红绿灯的位置，并出现“显示侧栏”按钮。

## 资料库

| 区域 | 行为 |
| --- | --- |
| 侧栏 | 全部 / 最近打开 / 已收藏 / 待复习 + 文件夹 + 未分类，点一下即筛选，标题同步变化 |
| 工具栏 | 图标/列表（⌘1/⌘2）、排序（循环切换）、搜索（⌘F 聚焦，Esc 清空）、新建（⌘N） |
| 内容 | “继续学习”（仅全部 + 图标视图 + 无搜索时）、网格或表格、空结果、首次启动拖放区 |
| 选中与打开 | 单击选中（访达样式），双击、↩ 或 ⌘↓ 打开，Esc 取消选中 |

## 学习集工作区

工作区由左侧导航、顶部 Tab、主内容区和右侧内容栏组成。文档区不再单独展示文件名标题行，AI 入口位于 Tab 行最右侧。

| 左侧入口 | 打开方式 |
| --- | --- |
| 文档、脑图 | 共用一个“文档与脑图”Tab；切换文档或脑图会在此更新主体。顶部布局按钮控制只看原文、左右分栏、只看脑图。 |
| 笔记 | 每篇笔记单独一个 Tab。 |
| 生词本、复习 | 各自只有一个 Tab，重复点击会回到已打开的页面。分支/标签复习仍在复习 Tab 中进行。 |
| 标签 | 在右侧内容栏展开，不创建 Tab。跨脑图汇总匹配主题；选中结果后关闭标签面板，回到文档与脑图 Tab，切换正确的脑图和文档，并定位主题。 |

从主内容中的链接、出处打开的文档、脑图、笔记、生词详情显示在右侧，归当前主 Tab 所有。切换 Tab 保留各自参考与阅读状态；关闭 Tab 时销毁它的参考。共用 Tab 换文档或脑图时关闭旧参考。右侧参考中的链接继续在右侧打开，保持原来的主 Tab。

右侧是完整的内容展示栏，AI 助手、标签和参考内容共用这一位置，内部没有分类切换栏。AI 从顶部按钮打开，标签从左侧打开。临时打开 AI 或标签不会改变主内容的分栏方式；返回原 Tab 时恢复其右侧状态。参考阅读拥有独立的页码、缩放、查找和焦点，但编辑写回同一学习集。

同一学习集的编辑和撤销按发生顺序共享；参考区关闭时先完成已排队的保存，再释放后台状态，避免丢掉刚写的内容。参考区内的 AI 操作使用该参考自己的上下文、对话和草稿；关闭 AI 后返回原参考，主体的对话不受影响。

Tab 与右侧参考是本次窗口会话的状态，不改变学习集文件格式。

⌘W / Ctrl+W 关闭当前主 Tab。查找、缩放和编辑等命令跟随键盘焦点，聚焦右侧参考时作用于参考内容。

| 面板 | 行为 |
| --- | --- |
| 侧栏 | 学习集名称（点击回到资料库，⇧⌘L）、搜索框、脑图 / 文档 / 学习三个分组。搜索会同时过滤所有分组，都没有匹配时显示“没有匹配的条目”。 |
| 工具栏 | 标注工具（选择、高亮、框选、手写、文本）、6 色、“摘录同步到脑图”开关；布局（⌘1 只看原文 / ⌘2 分栏 / ⌘3 只看脑图）；AI。 |
| 原文面板 | 共用 Tab 内的 PDF（触控板平移缩放）、底部浮动页码（上一页 / 下一页）。没有文档时显示“导入 PDF”。默认是选择工具：选中文字后在选区上方弹出浮动工具条（颜色点摘录、仅高亮、复制、添加笔记；E / H / ⌘C），点击已有高亮弹出同样的工具条（换色、加入脑图 / 定位卡片、复制、删除）；Esc、点别处、翻页或滚动时关闭。高亮笔（⇧⌘H）下松开鼠标即摘录。框选（⇧⌘R）下在页面上拖出矩形，松开即生成带截图的图片卡片，原文上以描边标出该区域；选色不会退出框选。原文面板左侧有可开关的页面侧栏（⌥⌘S；⌥⌘1–4 切换模式）：缩略图（懒加载，点击跳转）、目录（读 PDF 自带书签，可折叠，高亮当前章节；没有目录时不显示）、书签（⌘D 添加或取消，右键重命名、删除，保存在学习集里）、标注（本文档的高亮和摘录，点击定位）。⌘F 随键盘所在区域区分：焦点在原文面板时在 PDF 里查找（命中数、⌘G / ⇧⌘G 上一个下一个、命中处高亮），否则仍是侧栏搜索。点页码可直接输入跳转；⌥↑ / ⌥↓ 或 Home / End 到首页、末页；⌘[ 返回上一个位置。 |
| 脑图面板 | 左上：脑图名 + “新摘录 → 目标” + 脑图/大纲；右上：添加主题、添加笔记、移除；右下：缩放。画布可平移缩放；单击选中，⇧ / ⌘ 点击或在空白处拖出选框多选；双击、F2、空格或直接打字原地编辑主题、摘录标题和笔记（Enter 确认、Esc 取消、点别处确认；笔记用 ⇧Enter 换行）；XMind 快捷键见菜单栏“脑图”；Esc 选中根节点。摘录和图片卡片右上角箭头 = 定位原文。 |
| 分隔线 | 拖动调整比例，双击恢复 50 : 50；窗口太窄放不下两栏时只显示原文；右侧栏展开时使用较紧凑的主内容最小宽度，极窄窗口的右侧栏覆盖在主内容上。隐藏的面板不会被销毁，切换布局时保留滚动位置等状态。 |

⌃⌘S 收起或展开侧栏；⌘F 聚焦侧栏搜索框（侧栏收起时会先展开）。

## 命令与快捷键

所有命令定义在 `lib/app/app_commands.dart`：

- macOS：生成菜单栏（应用菜单含“关于”“设置… ⌘,”“服务”“隐藏”“退出”；文件、显示、窗口、帮助），快捷键由菜单处理。
- Windows / Linux：同一组命令注册为快捷键，⌘ 自动换成 Ctrl。
- 工具栏按钮的提示文字里会显示快捷键（`AppShortcuts.tip`）。

## 设置

“设置…”（⌘,）里可以修改外观（跟随系统 / 浅色 / 深色）和语言（跟随系统 / 简体中文 / English），修改立即生效，并保存在 `SharedPreferences`。系统强调色、“降低透明度”和“减少动态效果”会实时跟随 macOS 的系统设置。

## 新增一个界面

1. 在 `features/<name>/` 写 `Notifier` 控制器和界面，界面用 `MMWindowScaffold`，并传入 `WindowChrome` 回调。
2. 在 `navigation.dart` 增加路由，在 `AppShell` 里映射到界面。
3. 在 `AppMenus` 里加入它的命令。
4. 文案写进两份 ARB，测试写在 `apps/marginmind/test/`。
