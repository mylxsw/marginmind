# 应用框架：窗口、面板与命令

本文说明主界面的结构，以及面板如何展开、收起、切换和搜索。设计依据见 `design/canvas/Library.dc.html`、`Main.dc.html` 与 `Components.dc.html`。

## 窗口骨架

每个界面都由 `MMWindowScaffold` 组成：

```
┌──────────┬─────────────────────────────────────────────┐
│ ● ● ●  ⊟ │ 标题 / 副标题           [胶囊] [胶囊] [搜索] │  ← MMToolbar（56）
│          ├─────────────────────────────────────────────┤
│  侧栏     │                                             │
│ (悬浮玻璃) │                  内容区                     │
│  236      │                                             │
└──────────┴─────────────────────────────────────────────┘
```

- macOS 上标题栏透明、内容铺满窗口，系统红绿灯被移到侧栏顶部（`DesktopWindow.initialize`）。
- 工具栏和侧栏顶部的空白处可以拖动窗口，双击则缩放窗口。
- 侧栏收起时以 320ms 的动画滑出；工具栏左侧自动留出红绿灯的位置，并出现“显示侧栏”按钮。

## 资料库

| 区域 | 行为 |
| --- | --- |
| 侧栏 | 全部 / 最近打开 / 已收藏 / 待复习 + 文件夹 + 未分类，点一下即筛选，标题同步变化 |
| 工具栏 | 图标/列表（⌘1/⌘2）、排序（循环切换）、搜索（⌘F 聚焦，Esc 清空）、新建（⌘N） |
| 内容 | “继续学习”（仅全部 + 图标视图 + 无搜索时）、网格或表格、空结果、首次启动拖放区 |
| 选中与打开 | 单击选中（访达样式），双击、↩ 或 ⌘↓ 打开，Esc 取消选中 |

## 学习集工作区

| 面板 | 行为 |
| --- | --- |
| 侧栏 | 学习集名称（点击回到资料库，⇧⌘L）、搜索框、脑图 / 文档 / 学习三个分组。搜索会同时过滤所有分组，都没有匹配时显示“没有匹配的条目”。 |
| 工具栏 | 标注工具（选择、高亮、框选、手写、文本）、6 色、“摘录同步到脑图”开关；布局（⌘1 只看原文 / ⌘2 分栏 / ⌘3 只看脑图）；AI。 |
| 原文面板 | 文档标签页（点击侧栏文档打开或切换；悬停显示关闭）、PDF（触控板平移缩放）、底部浮动页码（上一页 / 下一页）。没有文档时显示“导入 PDF”。高亮工具下松开鼠标即摘录；选择工具下选中文字、或点击没有卡片的高亮，会在底部弹出操作条（Esc 关闭）。 |
| 脑图面板 | 左上：脑图名 + “新摘录 → 目标” + 脑图/大纲；右上：添加主题、添加笔记、移除；右下：缩放。画布可平移缩放；单击选中、双击或 ↩ 重命名、Delete 移除、Esc 选中根节点。摘录卡片右上角箭头 = 定位原文。 |
| 分隔线 | 拖动调整比例，双击恢复 50 : 50；窗口太窄放不下两栏的最小宽度（420 + 360）时只显示原文。隐藏的面板不会被销毁，切换布局时保留滚动位置等状态。 |

⌃⌘S 收起或展开侧栏；⌘F 聚焦侧栏搜索框（侧栏收起时会先展开）。

## 命令与快捷键

所有命令定义在 `lib/app/app_commands.dart`：

- macOS：生成菜单栏（应用菜单含“关于”“设置… ⌘,”“服务”“隐藏”“退出”；文件、显示、窗口、帮助），快捷键由菜单处理。
- Windows / Linux：同一组命令注册为快捷键，⌘ 自动换成 Ctrl。
- 工具栏按钮的提示文字里会显示快捷键（`AppShortcuts.tip`）。

## 设置

“设置…”（⌘,）里可以修改外观（跟随系统 / 浅色 / 深色）和语言（跟随系统 / 简体中文 / English），修改立即生效，并保存在 `SharedPreferences`。系统强调色、“降低透明度”和“减少动态效果”会实时跟随 macOS 的系统设置。

## 新增一个界面

1. 在 `features/<name>/` 写 `Notifier` 控制器和界面，界面用 `MMWindowScaffold`，并传入 `WindowChrome` 回调。
2. 在 `navigation.dart` 增加路由，在 `AppShell` 里映射到界面。
3. 在 `AppMenus` 里加入它的命令。
4. 文案写进两份 ARB，测试写在 `apps/marginmind/test/`。
