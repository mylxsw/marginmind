# 体验审查：核心闭环真机走查

v0.4、v0.5 按验收清单解决了“能用”，这一轮看“好用”：在 Mac 上用 Release 构建，以一份长文档把“读 → 摘 → 图 → 回原文 → 复习”当成真实用户走一遍，记录体验问题并排出修复顺序。**只记体验问题，不提新功能。**

## 方法

- **构建**：`main` 上的 `b24198e`（v0.5.0），Release 构建，按 `Release` 工作流签名，临时 bundle ID `io.github.mylxsw.marginmind.review493`，空资料库开始。
- **机器**：Mac mini（Apple 芯片），macOS 26.6.2。前半程显示器为 1920×1080（1×），后半程系统切到 1512×949（2×）；按显示倍率有差异的问题单独注明。
- **文档**：自制的 301 页中英文混排 PDF（Chrome 打印生成，A4，每三章一章双栏，含图、表、公式，每页有页眉日期和页脚“文件路径 + 页码”）。内容为原创，截图可公开。
- **对照**：预览（Preview）与 MarginMind 并排打开同一份 PDF 对比。测试机上没有安装 MarginNote 4，XMind 没有并排运行；这两者的“期望”一栏按它们的现有交互约定来写，没有截图对比。
- **操作方式**：远程桌面自动化（点击、拖选、键盘、菜单、剪贴板）。触控板手势、输入法、帧率无法用自动化测量，本轮没有覆盖，留给人工补看。

截图在 [`ux-audit/`](ux-audit/) 目录。

## 汇总

| 优先级 | 含义 | 数量 |
| --- | --- | --- |
| P0 | 影响核心闭环或明显出错 | 4 |
| P1 | 明显不顺手 | 16 |
| P2 | 打磨 | 9 |

P0 一览：

- **U-B1** 回原文时 PDF 被放大并裁掉两侧文字，回不到原来的缩放。
- **U-X1** 跨页选择把页眉、页脚选进引文（已知问题）。
- **U-V1** 复习卡正面没有任何可回忆的内容。
- **U-G1** 调整窗口大小时崩溃一次（Impeller 渲染线程空指针）。

编号前缀：L 资料库，R 读，X 摘，M 图，B 回原文，V 复习，G 全局。

| 编号 | 现状 | 期望（参照） | 优先级 |

| U-G2 | Release 版的设置里有开发用的“组件库”按钮，点了会进入组件演示页。菜单里的同一入口已经用 `kDebugMode` 隐藏，设置页没有（`apps/marginmind/lib/settings/settings_sheet.dart:25`）。[截图](ux-audit/14-settings-gallery.jpg) | 和菜单一致，只在调试构建里出现。 | P1 |

## 分批修复

按代码耦合把问题分成 7 批，每批一个 PR。前 4 批包含全部 P0，相互独立，可以并行；后 3 批在其后。

| 批次 | 问题 | 改动范围 | 说明 |
| --- | --- | --- | --- |
| 1 回原文定位 | U-B1、U-B2、U-R2 | `mm_pdf` 的 `reveal`，阅读器缩放命令（`app_commands.dart` + 菜单），脑图“定位卡片”的视口 | 三者都是“把视口带到目标位置”。修 U-B1 后缩放状态要能恢复，所以缩放命令一起做 |
| 2 摘录文本与高亮 | U-X1、U-X2、U-X3 | `mm_pdf` 选区到文字和矩形的转换，摘录文字的生成 | 都在“选区 → 引文 + 高亮矩形”这条管道里。只影响新摘录，不迁移旧数据 |
| 3 复习卡面 | U-V1、U-V2、U-V3、U-V4、U-V5 | `review_screen.dart`、复习队列取卡片内容 | U-V1 的卡面方案需要项目所有者先确认，再动手 |
| 4 渲染稳定性 | U-G1、U-R1 | Flutter 引擎版本 / 渲染设置，复现脚本 | 先复现和定位，结论写回本文档；如需升级 Flutter，单独成 PR |
| 5 脑图视图 | U-M1、U-M2、U-M3、U-M4、U-M5 | `mind_map_canvas.dart` 的输入与取景，`mm_layout` 的平衡布局，卡片样式 | U-M2 的左右平衡布局改动较大，必要时拆成单独的 PR |
| 6 阅读器界面 | U-R3、U-R4、U-R5、U-R6、U-X4、U-X5 | 阅读器顶栏、页码胶囊、浮动工具条定位、工具栏、`MMSplitView` 窄窗口策略 | U-X4 复用卡片原地编辑，依赖第 2 批生成的摘录文字 |
| 7 资料库与无障碍 | U-L1、U-L2、U-L3、U-L4、U-G2 | 资料库、新建流程、`mm_design` 的语义标签、设置页 | U-L3 改 `MMInteractive` 的语义合并，所有用到它的组件一起受益，需要补语义测试 |

每批完成后，在真机上重走对应的章节并更新本文档的状态。
