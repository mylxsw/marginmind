## 页面结构

同步概览只回答当前连接、待确认状态和手动同步结果，唯一强调操作是“同步一次”；
尚未连接时改为“连接同步服务”。下方沿用既有 `MMSettingsGroup/Row`，提供四个明确入口：

- 连接同步服务：先选择 WebDAV / iCloud，只显示该服务需要的字段；迁移目标选项默认收起。
- 资料库与设备：设备名、其他已登记设备、供加入使用的资料库代码。
- 本地文件：按文件显示已验证/缺失/不符，缺失时在该项下载。
- 高级管理：历史复制预览与明确确认、缓存检查和无引用块清理。

首次启用明确“准备 → 重启 → 连接服务”，保留现有本机资料与身份校验；没有伪装成无重启热切换。
日常操作不会展开迁移/缓存细节，也不会把原始 UUID 放在概览首屏。

## 诚实边界

旧共享提交没有可信的写入时间字段，因此没有给旧冲突/恢复版本伪造时间戳，也没有拿设备时钟排序当胜出规则。
设备名来自已经接受的 profile，是显示名称而非认证身份。差异高亮为去除共同前后缀后的不同文本区间，
不是逐词语义 diff；长文复杂多处修改时仍需完整阅读。

恢复仍创建新身份副本，不复活原身份；列表保留文档、卡片数和摘录。
已存在但字节不符的原文件不会被自动覆盖；本轮没有新增“并排保留两份资源”的仓库事务或完整冲突文件管理器。
这些是明确保留的功能边界，不将本次视觉调整宣称为全部同步业务验收。
