# Mac 真机验收清单

每个版本发布前，在 macOS 真机上逐项确认（计划 Q-02）。组件测试已经覆盖逻辑，这份清单只关心**真机上的行为**：菜单栏、快捷键、输入法、拖拽、沙盒、签名。

## 怎么做

1. 从要发布的提交构建 Release 版，按 `Release` 工作流的方式签名（先 `--deep` 签内部代码，再带 `Release.entitlements` 签整个应用）。
2. 不要碰日常使用的数据：把 `apps/marginmind/macos/Runner/Configs/AppInfo.xcconfig` 里的 bundle ID 临时改成 `io.github.mylxsw.marginmind.reviewNNN`。应用是沙盒应用，换了 ID 就有独立的数据容器。验收完删除构建产物，不要提交这处改动。
3. 从空资料库开始，打开示例学习集，按下表顺序操作。
4. 结果写在文末的“验收记录”里：✅ 真机通过；🧪 真机上无法自动操作，由组件测试覆盖，有条件时再手动看一眼；❌ 不通过（附问题和修复 PR）。

| E-08 | 在空白处拖出选框；⇧ / ⌘ 点击；删除后撤销 | 选中的节点都有描边；批量删除一次撤销全部恢复 |

| E-11 | 键盘连续加节点直到超出视野；“脑图 › 居中到当前节点” | 编辑中的节点始终可见；居中命令把节点移到中央 |
| E-12 | 粘贴 500 行缩进文本，然后缩放、平移、适应窗口、撤销 | 操作流畅，没有明显卡顿；缩放比例显示和实际一致；一次撤销移除全部 |
| E-13 | 切到大纲，只用键盘写一棵三层的树 | Tab / Enter / ⇧Tab 与脑图一致 |
