## 0. 一页结论

- **补齐三件事，但不照搬 MarginNote 的“更多”菜单。** 截图里的菜单有 15 项，留白、背景、附属笔记本等都摆在一起。我们只做用户真正会用的三件：裁边、页边批注、对照阅读。每件事只有一个入口，用到时才出现，不用时不占地方。
- **裁边：一键完成，可以微调。** 页边很宽的文档，原文栏顶部出现一次“裁掉白边”胶囊（图标、按钮和 ×），点一下即可。工具栏“页面”菜单里也能开关（⌥⌘K），需要时进入“调整裁边”，拖四边，按所有页、奇偶页分开或仅本页应用。裁边只改变显示：原 PDF、导出和标注坐标都不变。自动裁边会把用户自己的笔迹算作内容，不会裁掉它。
- **页边批注：选中一句，直接写。** 浮动工具条新增“批注”（C）。第一次使用时页边自动展开，卡片就出现在那句话旁边，直接打字，点别处即保存，没写内容的批注不会留下。也可以在页边空白处点一下，在那一行旁边写。批注之间自动错开；悬停时，批注和原文互相高亮，并用虚线连起来。哪条想法值得整理，用户点“加入脑图”即可，之后修改页边，脑图卡片同步更新。
- **不为页边挤小正文。** 空间不够时（窄窗口、分栏、对照阅读），批注收成页边的黄色标记，点开就能查看和编辑。如果裁边能腾出空间，标记的弹层里直接提供“裁掉白边，展开页边”。
- **对照阅读：两栏同步滚动。** 工具栏新增“对照阅读”，可以选学习集里的另一份文档（同一本书的另一语言版本排在最前，标“推荐”），也可以导入。两栏同步滚动；页码对不上时，滚到对应位置点“对齐此处”。没有现成译本时，可以选“AI 逐段翻译”：先译正在看的部分，段落一一对应，悬停任意一段，另一边对应的段落也会高亮；译文存进学习集。两边都能照常划线、摘录、写批注。
- **三者能组合使用。** 对照阅读时每栏偏窄，所以对照模式下也会出现裁边提示；页边放不下时，裁边可以腾出空间。第 3.4 节定义了空间分配规则。

## 1. 用户场景与设计原则

| 场景 | 用户想要什么 | 对应功能 |
| --- | --- | --- |
| 扫描书、论文页边很宽，分栏后字太小 | 字大一点，又不用左右滚动 | 裁边 |
| 读到一句话有想法：疑问、联想、反驳 | 就在这句话旁边记下来，不打断阅读，回头重读时还能看到 | 页边批注 |
| 想法值得留下 | 一步放进脑图，不用重写 | 批注 → 加入脑图 |
| 读英文原著，手边有中文版或需要翻译 | 读到哪，另一边就对到哪 | 对照阅读 / AI 逐段对照 |
| 新旧版本、讲义和教材对照 | 两份文档并排，各自能标注 | 对照阅读（任意两份文档） |

原则：

1. **按需出现。** 提示每份文档只出现一次；页边在写第一条批注时才展开；对照阅读是一种模式，Esc 退出。
2. **不动原文件。** 裁边、批注、译文都存在学习集里（`studyset.json`），PDF 原样保留，导出默认是原始页面。
3. **不牺牲正文字号。** 空间分配优先保证正文可读，页边和对照让位（第 3.4 节）。
4. **和脑图打通，但不强制。** 页边适合随手记，脑图适合整理，由用户决定哪条批注进脑图。
5. **沿用现有交互。** 浮动工具条、高亮、画笔、脑图联动、⌘Z 都照旧，新能力只是在旁边加入口。

## 2. 与 MarginNote 的取舍

截图中“文档 - 更多”菜单逐项处理如下：

| MarginNote | 处理 | 理由 |
| --- | --- | --- |
| 裁边 | **做**，并加上自动裁边和一次性提示 | 用户需要它，但很少主动去菜单里找 |
| 页边评论区（开关） | **做**，但不需要先打开开关 | 写第一条批注时自动展开，空间不够时自动收成标记 |
| 双文对照 | **做**，命名为“对照阅读”，增加 AI 逐段对照 | 大多数用户手里没有现成译本 |
| 留白：正常 / 边距 / 折叠 | 不做 | 页边批注已经满足“在页边写”的需求，三档留白难以理解 |
| 空白背景（方格 / 横线） | 不做 | 手写空白纸属于以后 iPad / Pencil 的手写专题 |
| 附属笔记本、文档笔记本、卡片分组看板 | 不做 | 脑图和大纲已经承担这个角色 |
| 显示文档标签页、显示滚动条、切换工具栏模式 | 不做 | 现有应用已有文档切换和底部页码导航 |
| 手写在文字上层 | 不做 | 现有画笔已经画在页面上层 |
| 导出文档、添加书签、转到页码、编辑 PDF 页面、阅读设置 | 保持现状 | 已有或不属于本期 |

## 3. 交互设计（对应原型场景）

### 3.1 裁边（场景 1、2、9）

- **入口**
  - 一次性提示：文档左右空白合计超过 100pt，且未裁边时，原文栏顶部出现一个小胶囊：［裁边图标］［裁掉白边］［×］，不带说明文字。点 × 或用过一次后，这份文档不再提示。
  - 工具栏“页面”菜单（原“适合宽度”按钮，图标不变）：实际大小 / 适合宽度 / 适合整页 | ✓ 裁掉白边 ⌥⌘K | 调整裁边…
  - 开启后，“页面”按钮显示为选中态，表示当前文档已裁边。
- **自动裁边**：一份文档使用一个裁边框，滚动时页面宽度不会跳动。裁边框等于正文范围加 14pt 余量，保留页眉和页码，并扩大到包含用户的笔迹、高亮和批注锚点。开启后保持当前阅读位置，并显示 HUD“已裁掉白边，文字放大约 N%”，可撤销。
- **调整裁边**：进入后整页适配显示，裁掉的区域加暗，四边有手柄；上方工具条可选 **所有页 / 奇偶页分开 / 仅本页**，以及“自动”“不裁”“取消”“完成”。↩ 完成，Esc 取消并恢复。被裁掉的区域里如果有标注，会提示“N 处标注将被隐藏”（只是不显示，不会删除）。
- **不变的东西**：标注坐标、导出（默认原始页面）、OCR、搜索、页码。裁边按文档记住，跨设备同步。

### 3.2 页边批注（场景 3–6）

- **写批注**
  - 选中文字或点已有高亮，在浮动工具条上点“批注”（C）。锚点是选中的文字，原文下方显示细虚线。
  - 在页边空白处点击：鼠标移到页边，会出现“+ 写批注”和一条虚线，点一下就在这一行旁边写。这种批注只锚定在这一行，页面边缘显示一小段虚线刻度。
  - 选区跨段落、无法包成一个锚点时，退化为锚定在这一行。
- **编辑与保存**：卡片内直接输入，自动增高；点别处、Esc 或 ⌘↩ 都会保存。新建后什么都没写，这条批注直接消失；清空一条已有批注，等于删除它，可撤销。
- **排布**：卡片顶端对齐锚点所在的行，相互重叠时依次下移，间距 8pt；下移的卡片用短虚线连回原位置。悬停卡片或锚点时，两者高亮，并画出从锚点到卡片的完整虚线。
- **卡片操作**（悬停时显示在右上角）：加入脑图 / 在脑图中定位；“…”里有 6 种颜色、拷贝、删除。默认颜色跟随当前高亮颜色。
- **加入脑图**：有锚点的批注生成摘录卡片，标题是批注内容，正文是原文，并带出处，可以回到原文；没有锚点的批注生成笔记卡片。两者是同一实体的两种呈现，修改页边会同步到脑图卡片，在脑图中删除卡片后，页边批注仍然保留。操作后不切换布局，HUD 提供“查看”。
- **显示与收起**：工具栏“页边批注”按钮（⌥⌘M）显示当前文档的批注数。收起后批注不会消失，而是变成页边的黄色标记，点开可以查看和编辑。
- **空间不够时**：加上页边后，页面缩放低于实际大小的 78%，页边自动收成标记；空间够了再自动展开。如果裁边后放得下，标记弹层里提供“裁掉白边，展开页边”。

### 3.3 对照阅读（场景 7–9）

- **入口**：原文栏工具栏的“对照阅读”按钮，弹出菜单：
  - 学习集里的其他文档。和当前文档构成另一语言版本的排在最前，标“推荐”，右侧显示语言标签。
  - 导入另一份 PDF…（先加入学习集，再在右侧打开）。
  - 没有译本？AI 逐段翻译成中文 / English（目标语言取当前文档语言的另一种，跟随应用的翻译语言设置）。未连接模型、断网（且不是本机模型）、扫描版未识别时，这一项变灰并说明原因。
  - 已在对照模式时，菜单末尾有“退出对照阅读 Esc”。
- **布局**：原文栏分成左右两栏，中间是 34pt 的栏缝，放“同步滚动”开关和“对齐此处”。每栏顶部有标题条：文档名（点开可以换文档）、语言、当前页码；右栏还有 ⇄ 互换和 × 退出。进入时侧栏自动收起；原文栏宽度不足 900pt 时，脑图也暂时收起（HUD 说明，⌘2 可以随时打开）。退出后恢复进入前的布局。
- **同步滚动**
  - 两份 PDF：按页对应，用户设置的“对齐点”之间做分段线性插值。默认对齐点是首页 ↔ 首页、末页 ↔ 末页；“对齐此处”把两栏当前阅读线（视口高度 25%）所在的位置记为一个对齐点。对齐点按文档对保存。
  - AI 译文：段落一一对应，按段落精确同步；悬停任意一段，两边对应的段落同时高亮。
  - 同步可以关闭，两栏各自滚动。
- **标注**：两栏都可以划线、摘录、写批注（批注在对照模式下以标记显示）。在 AI 译文上摘录时，卡片正文是译文，出处指向原文对应的段落；在译文上不能写批注（译文栏的浮动工具条不出现“批注”）。
- **AI 译文**：从当前阅读位置开始逐段翻译，未完成的段落用占位条保持高度，所以译文出来后布局不会跳动。标题条显示“翻译中 n/N”，完成后显示“已保存”。译文按“文档 + 段落指纹 + 目标语言”缓存，存进学习集，离线可以查看。右栏标题条标“AI 译文”。

### 3.4 空间分配规则

按优先级从高到低：**正文字号 > 对照第二栏 > 页边批注 > 脑图 > 侧栏**。

| 情况 | 处理 |
| --- | --- |
| 页面 + 页边放得下（缩放 ≥ 实际大小的 78%） | 显示页边 |
| 放不下，但裁边后放得下 | 批注收成标记；弹层里提供“裁掉白边，展开页边” |
| 放不下 | 批注收成标记 |
| 进入对照阅读 | 收起侧栏；原文栏宽度不足 900pt 时收起脑图；页边收成标记；未裁边且页边很宽时显示裁边提示 |
| 退出对照阅读 | 恢复进入前的布局和侧栏 |

适合宽度时，最大缩放为 140%，避免单栏全宽时字过大。窗口大小、侧栏或布局变化后保持阅读位置，与现有规则一致。

### 3.5 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 写批注（浮动工具条打开时） | C |
| 页边批注开 / 关 | ⌥⌘M |
| 裁掉白边开 / 关 | ⌥⌘K |
| 调整裁边：完成 / 取消 | ↩ / Esc |
| 退出对照阅读 | Esc（没有浮层时） |
| 批注编辑：完成 | ⌘↩ 或 Esc |

菜单栏“显示”菜单加入以上三项，与 `app_commands.dart` 的现有写法一致。

## 4. 数据模型

全部存进 `studyset.json`，坐标沿用 `PageRect` 的 PDF 页面坐标（point）。

```text
Document
  + crop: DocumentCrop?          // 无 = 未裁边
DocumentCrop { enabled, mode: auto|manual, scope: all|oddEven|page,
               all: Insets, odd: Insets?, pages: {page: Insets} }   // Insets = 四边 point
MarginNote { id, documentId, page, anchor: AnnotationAnchor? | lineY: double?,
             text, colorIndex, nodeId?, mapId?, createdAt, updatedAt }
  // anchor 复用 Annotation 的 pages/rects + quote；二者必有其一
ComparePair { id, leftDocumentId, right: documentId | ai(targetLang),
              alignPoints: [(leftPage, leftY) ↔ (rightPage, rightY)], sync: bool }
TranslationCache { documentId, targetLang, paragraphs: {fingerprint: text}, model, createdAt }
```

- `MarginNote.nodeId` 保存关联卡片的 cardId，`mapId` 可选（缺省为主脑图），以 `(mapId, cardId)` 定位节点。批注是唯一编辑来源，关联卡片的标题编辑也回写批注。删除节点只清空 `nodeId` / `mapId`；删除批注时脑图卡片及出处快照保留，不弹确认。
- 格式版本 +1，在 `format_migration.dart` 里加迁移，旧学习集打开后没有任何变化。

## 5. 实现要点

- **裁边**：按 ADR 0004 采用按页源区域裁剪。`CroppedDocument` / `CroppedPage` 只用于显示，PDFium 渲染原页面的对应瓦片；不能通过缩小 `layoutPages` 冒充裁边。文本、链接平移到显示窗口，选区提交反变换回原始坐标；高亮、画笔、搜索定位和阅读线使用统一几何层。复用 pdfrx 的可见页虚拟化、相邻页预取、100 MiB 缓存和真实跨页文本选择。自动框合并文字与像素包围盒，扩大到包含用户标注，保留 14pt 余量；像素扫描在 `compute` 中执行，检测结果在阅读会话中缓存，应用参数存入 `DocumentCrop`。详见 `docs/decisions/0004-reading-geometry.md`。
- **页边批注**：页边是页面布局右侧的附加列，在同一个布局回调里加宽度。卡片层画在 `pageOverlaysBuilder` 之外的视口层，以便跨越页面边界排布。排布算法是按锚点 y 排序后依次下压，复杂度 O(n)，只为可见页计算。
- **对照阅读**：`ReaderPane` 承载两个 `PdfView`，共用缩放和工具状态；同步滚动在 `pdf_navigation` 上监听滚动位置，经过对齐点映射后驱动另一栏，带防回环锁。AI 逐段翻译走 `mm_assistant` 的模型层，不经过 Agent 工具，按可见范围优先排队，可取消，并沿用钥匙串、预算等现有安全边界。
- **测试**：裁边框计算、批注排布、对齐点映射、迁移各自写单元测试；阅读区写 widget 测试，覆盖批注新建 / 保存 / 丢弃、收成标记、对照进入和退出；macOS 验收按 `macos-acceptance.md` 补充用例。覆盖率目标 80% 以上。

## 6. 分批

1. **A：裁边。** 自动 / 手动、范围、提示、页面菜单、迁移。独立交付，收益最直接。
2. **B：页边批注。** 实体与存储、选区入口、页边列、排布、标记收起、加入脑图与同步。
3. **C：对照阅读（PDF ↔ PDF）。** 双栏、同步滚动、对齐点、互换和退出、空间规则。
4. **D：AI 逐段对照。** 段落切分与指纹、按可见范围排队翻译、缓存、悬停联动。
5. **后置**：iPad / Pencil 页边手写、导出带页边批注的 PDF、有模型时自动对齐两份 PDF 的段落。

3. **AI 逐段翻译使用助手的默认模型**，不新增设置项。

## 9. 界面文案原则（所有批次必须遵守）

- 不加多余的次级标签和说明，让布局本身说明问题。
- 不加多余的辅助文字、描述性文案和重复的界面微文案。
- HUD 只说结果（“已裁边”“已加入脑图”），附一个动作（撤销 / 查看）；状态已经能从界面上看出来时，不弹 HUD。
- 只有在缺了它用户会做错事时才写说明，例如 AI 不可用的原因、“N 处标注将被隐藏”。
