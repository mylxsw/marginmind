# P2-R3 研究界面

依据 `docs/phase-2-design.md` 第 3、4 节和原型场景 1、2、3、11、13。代码在
`apps/marginmind/lib/features/research/`，会话与请求由 P2-R2 的引擎负责（见 `research-session-engine.md`）。

## 结构

| 文件 | 职责 |
| --- | --- |
| `research_intents.dart` | 7 个意图、推荐规则、关键词（不把整段原文当搜索词）、按可用服务选默认方式 |
| `research_origin.dart` | 起点：选区（文档 + 页 + 矩形 + 原句、前后文、章节）或节点（路径、子节点，默认不发送） |
| `research_controller.dart` | 面板状态与请求编排：开始 / 稍后 / 加入当前问题 / 重试 / 取消 / 追问 / 基于资料回答 / 读取 / 粘贴 / AI 摘要 |
| `research_drafts.dart` | 面板自己的草稿（`type: ui`）：方式、关键词、确认的上下文、勾选、改写、摘取、所选资料、补充上下文、摘要 |
| `research_answer.dart` | 把 Markdown 回答拆成小节和要点，并按 `cites` / `[source:N]` 归属引用 |
| `research_settings.dart` | 服务（Anthropic / OpenAI / 兼容接口）、模型、地址、上限、是否显示将发送的上下文；Key 只在钥匙串 |
| `widgets/` | 启动卡、研究面板（解答 / 资料 / 阅读 / 已摘取 / 追问）、保存表单、研究笔记详情、原文标记弹出卡片、设置 |

## 入口

浮动工具条和高亮工具条的“研究”（R）、节点右键“研究「…」”分组、编辑菜单“研究所选内容…”（⇧⌘E，作用于选区，否则选中节点）、
⌃⌘R 与工具栏按钮、侧栏“研究”分组（会话及状态、稍后研究）。

## 面板与分栏

所有入口都带上起点：选区、高亮、⇧⌘E 和原文标记从原文打开，节点从脑图打开，侧栏会话与“打开研究”按会话起点类型决定，
工具栏和 ⌃⌘R 不改变分栏。分栏布局下从原文打开时收起脑图、从脑图打开时收起原文（面板已打开时同样适用），
关闭面板恢复第一次打开前的布局；保存到脑图而脑图收起时，提示里给“在脑图中查看”。

## 引文

证据只绑定被核对到的那一段：引用验证在提交给 AI 的段落里逐字匹配，证据记录该段的标识和引文，不取整篇摘要。
解答和详情里的引文最多显示 4 行，超出时可“展开 / 收起”；点击引文打开阅读视图并定位到该段落。

## 归属与保存

每个会话在创建时固定起点；结果只写回发起它的会话。界面在发请求前读取引擎的最新状态（`current`），
避免刚写入的草稿还没广播就被读成旧值。保存走工作区的一次更新：笔记、证据、来源、原文关联和脑图卡片
（可拆成子节点）一起写入，只占一步撤销；笔记 ID 在打开表单时生成，重复点击不会再建一条。
原文标记与脑图卡片都只引用同一条 `ResearchNote`，在详情里改标题或正文两处同步。

## 方式与服务

- 只搜索：论文走 OpenAlex；网页、视频、图片给出外部搜索（浏览器打开，不读取、不计入资料）。
- 问 AI（不联网）：只发送启动卡上确认的上下文。
- 联网研究：服务端搜索与读取；回答后在本机读取被引用的页面（不超过页面上限），逐字核对引用原文后才成为证据。
- 基于资料回答：只发送所选资料已保存的正文段落。
- 兼容接口没有联网工具，联网研究置灰。

## 未在本任务提供（按方案归入 P2-R4）

- 保存表单里的“加入复习”：研究笔记卡片的复习题面属于 P2-R4，界面暂不显示该选项，避免出现不起作用的开关。
- 资料的“稍后阅读”、网页图片保存到快照：同属扩展项，暂不显示。
