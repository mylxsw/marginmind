# 网页 AI 整理的三端设计走查

由 `integration_test/web_format_screens_test.dart` 在真实应用里逐屏走过，每个状态截取真实窗口。网页抓取和 PDF 打印都是真实的，只有模型回复是脚本写的，所以这里不能说明整理质量。

## 设备

| 总览图 | 设备 | 外观 |
| --- | --- | --- |
| [pc-dark](pc-dark.jpg)、[pc-light](pc-light.jpg) | macOS 窗口 1280×820 | 深色、浅色 |
| [ipad-portrait-dark](ipad-portrait-dark.jpg)、[ipad-portrait-light](ipad-portrait-light.jpg) | iPad Air 11 英寸模拟器，竖屏 | 深色、浅色 |
| [phone-dark](phone-dark.jpg)、[phone-light](phone-light.jpg) | iPhone 17 模拟器 | 深色、浅色 |

每张总览图包含 21 个状态（手机多一张 AI 关闭时的预览），从网页入口到重新抓取。手机总览图是最终代码的截图；iPad 和 PC 的总览图截于最后一个手机提交之前，那个提交只在打开开关时增加滚动。修复前后的对比见 [手机第一轮](before-after-phone.jpg)、[手机第二轮](before-after-phone-2.jpg) 和 [iPad](before-after-ipad.jpg)。

## 发现并修复的问题

### 功能设计

| 问题 | 影响设备 | 处理 |
| --- | --- | --- |
| 弹窗只开半屏，内容区约两百多点高，编辑、对照和 PDF 基本无法使用 | 手机 | 展开到最大高度（`phoneSheetExpanded`，和设置一致），内容区填满弹窗 |
| 点“查看对照”不跳到对应段落；切换标签会丢滚动位置 | 全部 | 内容区始终在同一棵组件树的同一位置，状态不再重建 |
| 整理完成后停在文末，看不到标题 | 全部 | 跟随输出结束后回到开头 |
| 第一段以被删除的面包屑命名；段名从“二、FSRS”跳成“FSRS” | 全部 | 去掉序号；没有标题时用保留下来的第一句话命名 |
| “重新整理”只在悬停时出现，还会撑高这一行 | PC | 改为常驻的图标按钮 |

### UI 设计

| 问题 | 影响设备 | 处理 |
| --- | --- | --- |
| 两层分段控件叠在一起 | 手机 | 合并为一层：未开始时为设置、预览；完成后为预览、编辑、对照、设置；整理中为排版、Markdown、整理进度 |
| 底部说明和三个按钮折成两行 | 手机 | 主操作移到标题行右侧，和其他手机表单一致；底部只留取消 |
| 状态文字被截断，操作条换行 | iPad 竖屏 | 窄栏把状态放到第二行 |
| 文字操作是白色，不像可点击，也和正文不对齐 | 全部 | 统一为左对齐的主色文字链接 |
| “重新整理”文字占位，段名被截短 | iPad、手机 | 改为图标 |
| 段落行比小标题缩进 6pt | 全部 | 高亮外扩，图标和小标题左对齐 |
| 对照的列标题会滚走 | PC、iPad | 固定在顶部 |
| “Markdown”和“实时预览”两个标题不在同一高度 | PC、iPad | 同高 |
| 错误文案“服务暂时不可用 其他段落…”缺标点 | 全部 | 分两行 |
| 写到最后一段时段距变窄，写完又跳开 | 全部 | 写作中也保留段距（助手回答共用这个组件，同样受益） |
| 确认框是单独写的 | 全部 | 改用共用的 `showConfirmSheet`，iPhone 上会是系统弹窗 |
| “按章节分段”后只有一个数字 | 全部 | 显示“4 段” |

### 手机端第二轮（用户指出手机样式问题后）

| 问题 | 处理 |
| --- | --- |
| 文字过大且时大时小：预览文字被放大了两次（手机正文基准已是 17pt，又按 13pt 换算） | 按平台基准换算，手机正文固定 16pt，代码 14pt |
| 没开 AI 时，一个滚动区里同时塞表单和预览，预览只露一截 | 用“设置 / 预览”分段切开 |
| 主操作在底部，和其他手机表单不一致 | 移到标题行右侧 |
| 弹窗没展开到最大高度，分段控件还会被滚走 | 用 `phoneSheetExpanded`，分段固定 |
| 确认框是半屏空白 | 按内容高度显示（这是共用的 `showConfirmSheet`，其他确认框也会变矮） |
| 整理进度页又放一遍文档名称和格式 | 整理中只显示进度 |
| 统计信息（段数、字数、用时）占一整行 | 手机上不显示，只有未整理完或需要确认时才多一行 |
| 说明文字、链接和状态图标比例失调；段落行低于触控高度 | 说明用脚注字号，图标 16pt，段落行 44pt |
| 编辑页重复显示“Markdown”标题；对照页警告图标独占一行 | 去掉重复标题；警告和操作放在一行 |
| 打开 AI 后，“正文会发送到…”落在可视区外 | 打开时自动滚到可见 |

## 没有覆盖的部分

- **iPad 横屏：** 测试请求了横屏，但模拟器保持竖屏，没有拿到有效截图。
- **iPhone 系统确认框：** 走查没有初始化原生呈现，截到的是共用的 Flutter 弹窗。
- **Android、Windows：** 没有运行。
- **真实模型：** 没有调用。
- **浅色下的 PDF 预览：** 白色页面落在白色弹窗上，没有边界。这是共用的 PDF 预览组件的现状，这次没有改。
- **网页背景的深浅：** 网页内容按设计不跟随应用外观，弹窗后面的灰色是遮罩盖在白色网页上。
