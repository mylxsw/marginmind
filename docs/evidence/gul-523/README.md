# GUL-523：脑图导出验收

macOS 26.6.2 / Apple Silicon，Flutter 3.47.2 Debug。本机没有 `macrun`，使用 Flutter 构建、直接运行应用和桌面自动化截图检查。

`apps/marginmind/benchmark/map_export.dart` 是可复现入口：500 张卡片，包含折叠分支、中文、英文、宋体摘录、图片、研究笔记、关联线和概要。运行 `flutter run -d macos -t benchmark/map_export.dart`，终端的 `EXPORT_ACCEPTANCE` 输出目录和图片尺寸；目录内生成 `map-500.png` 与 `map-500.pdf`，然后显示正式导出表单。完整导出文件附在任务验收评论中。

- `export-sheet-branch.png`：指定分支的预览与尺寸，切换范围后更新；外观和倍率沿用正式控件。
- `png-detail.png`：500 节点 PNG 的原尺寸局部，包含图片、研究笔记和全文摘录。
- `pdf-detail.png`：PDFKit 将同一 PDF 局部按 2× 栅格化，检查矢量文字、宋体和图片。

整图 PNG 为 2145 × 14915 像素，触发 32 MP 内存预算并自动降低倍率。PDF 为单页矢量文字；PDFKit 提取到 9478 个字符，包含中文、研究笔记和最后一个节点 499。原生 XCTest 另外验证 500 行中文/英文可搜索，以及分块拼接的位置、透明像素和越界尺寸拒绝。

自审修复了离屏图层挂载、关联线穿过中间卡片、长关联标签越界、图片缺失后切换格式绕过校验和异步切换范围时旧图片加载覆盖新状态的问题。解码图片按总像素预算分配，保持宽高比，不放大小图；退出或失败时释放图片、编解码器和离屏渲染资源。
