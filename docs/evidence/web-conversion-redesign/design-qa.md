## 对照结论

- 字体：沿用应用 SF Pro / PingFang 与 13pt 表单正文，标题 18pt；不复制生成图片中的字形误差。预览保留原文段落、标题与强调格式。
- 布局：来源摘要、名称、格式、正文预览、底部操作顺序一致。删除副标题及三项格式说明；来源与标题不再重复挤占正文预览。
- 色彩：沿用应用深色语义色与系统强调色。浅深色和用户系统强调色继续由主题控制；不写死生成图片中的半透明材质。
- 图标：使用既有 Lucide 字体，单选圆圈、文档与 Markdown 清晰。PDF 用库内文件格式图标替代生成图中的 Acrobat 形状，是可接受的图标差异。
- 文案：标题“保存到资料库”；“文档名称 / 保存格式 / 正文预览”；“取消 / 保存文档”。英语同步。
- 对照迭代：初次截图发现测试未加载 Material 圆圈字形，控件改为共用 Lucide 单选图标；名称框允许一到两行，减少桌面空白。最终截图重拍并对照后，无待修复 P0/P1/P2 问题。
