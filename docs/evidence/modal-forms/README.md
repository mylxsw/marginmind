# 共用表单弹窗优化

- 桌面表单改为居中展示，默认宽度 420；外框圆角 16，统一内容与操作区间距。
- MMSheet 内的表单标签置于控件上方；输入框与按钮使用统一的弹窗尺寸和圆角。
- 内容与底部操作区通过留白区分，按钮自动换行；正文过长时滚动，操作区保留。
- 新建脑图使用“创建”按钮，名称类弹窗标题去掉菜单省略号；保留默认全选、回车提交、Esc 取消。
- 删除学习笔记中重复的按钮换行处理，统一交给共用组件。
