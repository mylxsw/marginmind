# 翻译浮层的复制入口（2026-10-29）

按已确认的设计稿，将“复制译文”从顶部纯图标移到译文下方右侧，使用图标和文字组成的低强调按钮。顶部保留语言选择、互换和关闭。按钮使用项目现有图标与颜色令牌，11pt 文字和图标、26pt 高、7pt 圆角。

复制入口位于正文滚动区之外：长译文滚动时按钮保持可见，复制内容包含未显示在视口里的全部译文。加载与失败状态不显示空的操作行。复制反馈沿用现有 HUD。

- `reference.png`：用户确认的设计稿，完整保留原文件。
- `copy-footer-dark.png`、`copy-footer-light.png`：同一原文与译文的实际 macOS Flutter 组件截图。
- `copy-footer-narrow-long.png`：800×600 窗口内长译文滚动后的实际截图。

设计核对记录在仓库根目录 `design-qa.md` 的本次章节。验证覆盖复制按钮位置、顶部不再重复复制图标、长文滚动后仍可点击、复制完整内容、语言切换和取消、浅色与深色状态。15 项浮层测试和 28 项关联回归通过，macOS Release 构建通过。截图与自动化测试不代表已替换运行中的应用或完成安装版人工验收。

用户要求进一步缩小后，按钮从 30pt 调到 26pt，文字从 12pt 调到 11pt，图标与内边距同步收紧。浅色、深色和窄窗口长文的 3 项已有测试重新通过，截图已更新。
