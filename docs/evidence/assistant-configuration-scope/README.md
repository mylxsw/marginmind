# 配置问题的范围纠正

之前把配置入口和错误提示的设计扩大为整个助手侧栏改版，超出了用户要求。本次撤回正常助手界面的无关变化。

恢复内容：解释、总结与更多操作回到输入框上方，引用回到输入框内，输入框保持底部；模型、联网、斜杠命令、新对话和设置按钮恢复原来的入口；问题气泡、回答操作和空对话建议也恢复原样。`assistant_composer.dart`、`assistant_context_summary.dart`、`assistant_messages.dart` 与改版前 `f5e270b` 完全一致。

保留内容：统一从模型设置配置服务，简短配置提示，无“重试读取”，凭据不可用时保留已有回答并隐藏不可用输入；此前的凭据保存和读取修复不受影响。上游平台适配保留。

验证：

- 静态分析通过。
- 84 项助手、设置、语音及手机布局测试通过，包括明确断言解释与引用属于底部输入区域的回归测试。
- 浅色、深色、窄窗口三组真实 Flutter 截图通过并检查。
- macOS Release 构建通过，已启动新构建并在已有真实对话中确认解释、引用和模型/联网控件恢复原位置，没有发送新的模型请求或修改文档。
- `restored-composer.png` 为实际 Flutter 截图，显示恢复后的输入区域。

之前侧栏设计的对照图已标记为撤回的历史方案，不能作为当前界面说明。此前发现但未定位的原生崩溃没有据此宣称修复。
