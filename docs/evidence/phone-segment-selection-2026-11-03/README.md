# 手机分段选择配色修复

用户截图中的安卓新建学习集，深色底槽与选中项均使用接近的卡片色，无法清楚辨认当前来源。

手机的共享分段选择控件改用专用选中底色（深色为 #636366），并绘制细边框。未选中项维持原底色，选中项仍加粗。iPhone原生分段控件及iPad、PC的原有分支保持不变。

实际安卓模拟器验证了深色、浅色下“空白 / 文档 / 网页”的切换，以及深色软键盘弹出场景，共7张截图，全部逐图复核。见[截图总览](overview.jpg)和[运行日志](run.log)。共享组件已有点击测试通过，静态分析无问题。来源指纹见[build-source.json](build-source.json)；该记录在修复未提交时生成，Dart指纹包含本次修复。
