# 摘录同步与旧标注编辑反馈

2026-10-30

先选中文字，再点浮动工具栏的高亮或划线，原先只创建标注，漏掉了“摘录同步到脑图”开关。现在按开关把新标注加入当前脑图；标注与节点在同一次编辑中创建，可一起撤销。高亮快捷键也遵守该开关。编辑旧标注保持原有标注和关联节点。

文字阅读器和 PDF 的点选按每行实际范围判断，手指允许 12 个逻辑像素的偏差，鼠标允许 3 个；真正点中的标注优先，否则选择最近的标注。长按旧标注进入编辑。文字阅读器在编辑期间持续画蓝色边框，工具栏显示当前标注类型的选中状态，退出后清除。
