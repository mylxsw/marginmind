# 全文翻译与脑图引用修复验证

日期：2026-11-01。

## 问题与修复

- 用户截图显示失败阶段为“组织脑图”，错误为 `noValidMapContent`，43 行全部因 `unknownParent` 被拒绝。这能证明父节点引用无法解析，但截图没有原始模型响应，不能据此断言它具体使用了哪一个错误别名。
- 生成请求明确区分输入要点 ID 和输出主题引用，并给出根引用及合法已有父节点。解析器暂存先于父节点返回的子节点，父节点出现后仍用原校验器解析，不猜测归属。全部父节点无效时自动纠正重试一次；持续无效或循环引用仍明确失败。
- 阅读器移除即时逐段翻译入口，统一到“更多 → 全文翻译…”。先确认源语言、目标语言、范围和要求，再启动任务；12 种语言共用同一流程。相同源语言和目标语言不能开始。
- 网页、Markdown、电子书以原文段落作为翻译任务坐标，避免读取不存在的 PDF 页码。任务摘要查询全部支持的语言；预估计入逐段请求开销。已完整翻译的文档提供“查看译文”，不重复发送请求。
