# 节点附属笔记 · 接入验收（2026-10-31）

final result: passed

用户选定第 2 版「节点内折叠」，随后明确要求接入应用、复用现有组件与样式。本轮调整脑图展示；大纲保留逐条访问笔记的方式。

## 结果与实现边界

- 普通笔记显示在所属节点底部，默认收起并显示数量；展开、编辑均在同一节点内完成。无笔记时没有底栏。
- 使用 MMInteractive、MMButton、MMInlineTextField、NoteFormatBar、MMIcons 和现有颜色、字体、间距令牌。笔记沿用正文 13pt / 19pt 行高，编辑沿用现有轻量按钮。
- 新增后编辑、取消、撤销/重做、右键删除、键盘导航均沿用现有控制器。方向键在脑图按可见主题移动；大纲仍能逐条定位笔记。
- 原有笔记与保存格式无需迁移。视图将普通笔记投影到所属卡片；笔记下的主题保留且按原阅读顺序显示。多脑图使用各自的归属关系。导出图片/PDF同样将笔记内容放进所属卡片。
- 没有归属的根笔记，以及已用作关系线/概括锚点的结构性笔记保留原有独立身份，避免破坏现有连接。

## 五项外观检查

1. 字体与层次：原文沿用宋体，自己的笔记沿用系统正文；标题、计数与编辑按钮沿用现有字号。生成稿里的放大字号不替换应用令牌。
2. 间距与布局：同一外框内使用细分隔线；展开只增加节点高度，主题仍是独立分支，连线和折叠按钮连接原文区；长笔记换行，编辑按钮与正文不重叠。
3. 色彩与令牌：深浅色均复用现有主题；原文颜色遵循原注释色，分支线遵循当前脑图配色，不引入写死的青色线或新按钮皮肤。
4. 图标与资产：全为现有图标/原生控件，无位图UI依赖。最终证据使用原生窗口字体，普通widget测试的字体占位截图未用作验收。
5. 文案与状态：计数有中英文翻译；单条、多条、空笔记栏、编辑、取消、撤销、重做均检查。

## 修订记录

- 首轮撤销/重做测试发现节点由窄主题变宽时，动画中的布局会挤压正文。改为按目标宽度布局笔记、由外框逐步裁切显示，原生测试复核通过。
- CJK字体测量的行高有小数误差，沿用既有卡片的2pt文本余量，消除多笔记底部溢出。
- 补齐笔记右键菜单和可见节点导航；附有笔记的可调整宽度卡片仍尊重用户设置的200–480pt宽度。
- 同画布复核后没有待修复P0/P1/P2问题。编辑按钮采用现有MMButton.plain，代替生成稿的自定义描边，符合用户复用现有样式的要求。
