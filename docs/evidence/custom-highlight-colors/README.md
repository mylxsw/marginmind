# 高亮按钮状态与自定义颜色（2026-10-29）

刷子未启用且色板未打开时不设置颜色 tint，使用与相邻按钮一致的普通图标颜色。启用工具或打开色板时才显示当前标注颜色。

“更多颜色”打开真正的自定义选色面板：六个预设色、饱和度/明暗色盘、可拖动的色相条、HEX 输入、即时色块预览。色盘调整只是草稿，点“完成”才应用，取消或 Esc 不改变当前颜色。非法 HEX 会禁用完成按钮。色盘支持键盘方向键，色相条使用标准滑块键盘和辅助功能。

自定义色保留精确 RGB，不映射到最近的预设色。原有六色的存储 ID 0–5 不变；自定义色使用 `0x01000000 | RGB`，继续通过既有 `colorIndex` 字段保存。PDF、脑图、大纲、复习、批注的显示统一通过 `MMAnnotationColor.fromIndex` 读取；批注原来的直接数组索引已移除。使用 JSON/剪贴板转存和磁盘重开验证了自定义色不丢失。

当前颜色与使用次数仍保存到偏好设置。常用色按频次和时间排序；当前自定义色即使还未用于标注，也能在快捷色中直接复用。拖动色盘不累计使用次数。
