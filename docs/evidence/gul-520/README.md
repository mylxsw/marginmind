# GUL-520 研究界面真机验证

2026-10-27，Mac mini（Apple 芯片），macOS 26.6.2，Flutter 3.47.2。`flutter build macos --release` 后去掉沙盒签名（同
[GUL-512](../gul-512/README.md)），以临时 bundle ID `io.github.mylxsw.marginmind.research520` 和独立数据目录启动，打开示例学习集。

## 服务与限制

- **没有真实 AI 服务的 Key**。AI 用本机替身：一个 OpenAI 兼容的 `chat/completions` 流式接口（`127.0.0.1:18765`），在设置里选“兼容 OpenAI 的服务”
  填本机地址。回答是按请求拼出的固定模板（问题、所选上下文、所给段落），不是模型输出；问题带“慢”时等 60 秒再答，用来制造进行中的请求。
- **搜索与正文提取是真实网络**（只搜索 / 联网研究里的资料列表、阅读视图都是真实网页与论文）。
- 自动化工具不能在 PDF 上拖出文字选区，也不能给注入的按键带上 ⌘ 修饰键。PDF 上的高亮用 PDFKit 按页面文字算出坐标写进学习集，
  入口统一从“点高亮 → 工具条 → 研究”进入；选区与 ⇧⌘E / ⌃⌘R 由组件测试覆盖，需物理键鼠复验（见验收清单）。

| 场景 | 截图 | 结论 |

| 2 从脑图节点解释，不联网，默认不进复习 | `23-node-menu` `24-node-launcher` `25-offline-answer` `27-node-saved` | 节点菜单“研究 ▸”；解答标“不联网”，保存表单“加入复习”默认关 |
| 3 请求期间切换 | `29-running` `30-switch` | 进行中再发起时可选“作为新研究 / 加入当前问题”，面板与侧栏各自显示所属会话 |

## 真机发现并已修复

- 启动卡底栏、运行状态行、保存栏在中文下被挤压截断 → 改为可伸缩布局。
- “重试”重跑了上一条之外的请求 → 记住最后一次请求。
- 完成时间随草稿写入变化 → 单独记录完成时间。
- 整个面板在辅助功能里被合成一个文本框 → 文本框自成语义节点。
- 解答里的资料引文过长（`17-answer`）→ 最多显示 4 行。
- 保存表单的位置路径在研究卡片下显示空段；0 个来源 / 0 处标记的文案 → 按卡片显示名与数量改写。
