# 顶部 Tab 外观调整

final result: passed

用户反馈：原 Tab 过于接近工具栏按钮，选中页只有底部蓝线，关闭按钮及重复标题提示干扰阅读。

本轮改为 36pt 高的圆角选中标签（触摸为 44pt），统一标签宽度与间距；选中页文字略加重，未选中页降低视觉重量。活动页保留关闭按钮，其他页在悬停或键盘聚焦时显示，位置预留以避免标题挤动。短标题不重复弹提示，截断的长标题仍可查看全文。标签放不下时出现“已打开的标签页”列表，并自动滚动到选中页。

布局按钮使用共同底座，与右侧 AI 入口用短分隔线分组。主内容、参考归属与 Tab 关闭规则沿用此前方案。
