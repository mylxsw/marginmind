# 高亮入口与划词翻译（2026-10-29）

主工具栏与划词工具条共用一个带当前颜色的刷子。未选中时刷子使用普通按钮颜色；选中或打开色板时显示当前颜色。点击向下展开三个常用色及彩色加号，彩色加号展开自定义色盘，支持拖动选色、色相调节和 HEX 输入，并保留六个预设色；空间不足时浮层改在上方显示。划词后选色只创建高亮，摘录到脑图改为独立按钮；已有高亮使用同一入口改色。复制位于后续功能区首位，AI 保留在最右侧。

颜色统计在高亮、改色或摘录成功后记录，单纯选择颜色不增加次数。排序综合使用次数与最近使用时间；当前颜色和统计保存在本机，重新打开仍有效。

划词翻译复用已有直接翻译接口，显示独立译文浮层，可复制、重试；关闭会取消未完成请求并保留选区。设置 → 阅读提供自动中英互译、英文 → 中文、中文 → 英文三个方向。默认自动判断：含汉字的选区译为英文，其余译为中文；混合语言或特殊文本可通过固定方向覆盖。未配置模型、离线云模型和请求失败均显示明确状态。
