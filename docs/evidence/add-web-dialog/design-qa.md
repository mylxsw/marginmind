# 添加网页对话框

final result: passed

采用第一版设计，按用户要求删除标题下方与输入框下方的两段说明。保留“网页地址”标签、输入框内的地球图标和分隔线，以及右下角取消/打开；桌面端补充关闭按钮。继续使用现有 MMSheet、MMButton 和 MMTextField。

## 视觉核对

- `design-selected.png`：按反馈修订的设计稿。
- `comparison.png`：上方为设计稿，下方为实际 Flutter 组件截图；统一为 1080 像素宽的弹窗裁剪。参考稿原图 1764×896，组件桌面视口 1264×640、截图倍率 2。比较聚焦弹窗，不比较模拟文档背景。
- `desktop-dark.png`、`desktop-light.png`：实际组件为 540×220 逻辑像素，居中显示；输入框 40 高，图标位于输入框内部。无两段描述文字。
- `phone-dark.png`：390×700 视口，沿用现有底部弹窗及顶部打开按钮，网址输入可横向滚动，无组件溢出。
- 字体：生产代码沿用应用原生字体与字号；截图工具为测试引擎加载 Arial 和 PingFang，避免默认测试字体方块。标题 15、标签 12、正文 13 为项目现有规范，相比生成稿更克制，作为现有产品约束保留。
- 间距：24 外边距，标题至表单 20，标签至输入框 8；输入框下保留单行错误提示空间以防校验时按钮跳动。
- 颜色：使用现有语义色和系统强调色；没有生成稿中的渐变材质。深浅主题均可读。
- 图像和图标：无业务图片；图标复用 MMIcons.web、MMIcons.close，未增加装饰素材。
- 文案与行为：标题、网页地址、取消、打开；仅输入有误时显示校验信息。修改网址立即清除旧错误；回车继续打开网页。

没有待处理的 P0/P1/P2 问题。测试引擎的阴影与原生字体不能代表安装版最终显示效果；本次未重新构建或启动已安装应用。
