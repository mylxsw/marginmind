# 实心控件统一白色前景

日期：2026-11-01。

final result: passed

## 问题与修复

用户反馈蓝色主按钮应使用白字，而且所有页面需要统一。原因是上一版 `readableForeground` 直接比较黑白对比度，选数值更大的一方；系统蓝色上黑色数值略高，于是文字、勾选与发送图标变成黑色。

共享规则改为实心控件白色优先；白色对比度低于 3:1 的浅黄、浅橙底色才使用深字。系统强调色、背景色、按钮尺寸与文案均未改动。普通正文和次级文字继续保持原有的 4.5:1 检查。该规则是用户确认的控件视觉选择，不宣称当前系统蓝底上的小字号白字达到正文的 4.5:1。

同一入口覆盖 `onAccent`、`onResearch`、`onVocabulary`、共享 MMButton、Material 主按钮及复选框勾选，各页面不再单独修补。
