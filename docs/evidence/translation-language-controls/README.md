# 划词翻译内调整语言（2026-10-29）

浮层标题改为“原文语言 ⇄ 译文语言”：左、右菜单可直接选语言，中间按钮互换方向，关闭保留在顶部右侧，“复制译文”位于译文下方右侧。语言包括简体中文、繁体中文、英文、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语；原文还可选择自动检测。

打开时继承设置中的默认方向。浮层里的选择只影响本次翻译，不修改默认值。更换任一语言会重新翻译当前原文；选回相同选项不会产生新请求。原文与译文选择相同语言时显示提示，不调用模型。

互换使用已有译文作为新的原文，同时交换两个语言。自动检测不提供一个可确认的原文语言代码，因此在自动检测状态下会提示先选择原文语言；不凭本地字符猜测，把法语等错误当作英文交换。

更换语言会立即取消旧请求。每个请求捕获自己的原文和语言，并校验是否仍为当前请求；旧回答、旧错误和迟到的凭据读取都不能覆盖新结果或发起过时翻译。关闭会取消当前请求，原来的 PDF 选区保留。

共享翻译接口增加可选的原文语言参数，使用受支持的语言代码生成明确的源/目标语言提示；未知代码直接拒绝。全文对照翻译仍使用原有默认调用方式。模型请求不携带工具，文档内容继续作为不可信原文处理。

截图是加载真实字体后的 Flutter macOS 组件渲染。验证覆盖语言菜单、连续切换和迟到结果、窄阅读区、互换后的实际原文、同语言提示、复制与关闭；模型接口测试逐一核对 12 种目标语言及明确原文语言进入请求。使用测试模型，未进行真实模型多语种质量验收，也未替换正在运行的应用。
