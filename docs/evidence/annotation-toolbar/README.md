# 标注工具栏：颜色与工具分离

修改范围仅限选中文字后出现的浮动工具栏。顶部页面工具栏恢复原来的选择、荧光笔、画线笔等按钮，以及各自的弹出方式和连续标注设置。

浮动工具栏依次为颜色圆圈、荧光笔、画线笔。选区内两种笔共用当前颜色，换色不切换工具。颜色面板沿用横向浮动工具栏：四个最近使用颜色、第五个“更多颜色”图标；画线笔模式在其后追加分隔线及实线、虚线、点线、波浪线。没有纵向标题或文字入口。

选区应用标记后保留工具栏及已打开的设置面板。切换两种笔修改同一条标记，保留关联卡片，支持撤销；选择颜色本身不会给尚未标记的选区创建标记。已有标记的颜色可直接修改。共用颜色及画线样式可在重启后恢复。

更多颜色图标打开原有自定义色盘，取消不改色，确认后保持选中的笔和同一条标记，并更新最近颜色。新建和实际改色记录使用历史，单纯选择尚未应用的颜色不计为标记使用。

窄屏保留三个标注按钮，将导图和翻译入口收进“更多”；320pt 手机和 768pt 平板的工具栏、颜色面板通过边界检查，过长的颜色／线型横栏可横向滚动。Esc 先关闭选区的颜色面板，保留当前工具和选区。

截图均由实际 Flutter 组件导出，像素密度为 2 倍。`highlight-settings-*` 和 `underline-settings-*` 同时包含选区工具栏和对应横栏；`toolbar-*`、`highlight-palette-*` 和 `underline-palette-*` 为各组件局部。`page-toolbar-*`、`page-underline-palette-*` 验证顶部页面工具栏恢复原样。

验证：13 个相关测试文件共 129 项通过；自定义颜色选定后的最近颜色刷新另由 8 项专项测试验证。`flutter analyze --no-pub` 无问题，`flutter build macos --release --no-pub` 成功。PDF 拖选画线由测试后端验证，真实书籍的使用手感由本地试用确认。

复现截图：在 `apps/marginmind` 目录，将 `MM_SCREENSHOTS` 指向本目录绝对路径后运行 `flutter test --no-pub test/annotation_toolbar_test.dart`。
