# 标注工具栏：颜色与工具分离

选中文字后的浮动工具栏采用一次性标注操作。顶部页面工具栏继续保留选择、荧光笔、画线笔等按钮，以及各自的连续标注设置；颜色小工具栏即时打开。

浮动工具栏依次为颜色圆圈、荧光笔、画线笔。选区内两种笔共用当前颜色，换色不切换工具。颜色面板首帧完整显示，无淡入等待，沿用横向浮动工具栏：四个最近使用颜色、第五个“更多颜色”图标；画线笔模式在其后追加分隔线及实线、虚线、点线、波浪线。没有纵向标题或文字入口。

选区中的荧光笔、画线笔默认均不选中，点击时只短暂显示操作反馈；应用成功后收起选区工具栏和色板，并清除临时选区。失败时保留选区，便于重试。重新点击已有标记可换色、改线型，或转换为另一种标记，保留关联卡片并支持撤销。选择颜色本身不会给尚未标记的选区创建标记。共用颜色及画线样式可在重启后恢复。

更多颜色图标打开原有自定义色盘，取消不改色，确认后保留同一条标记并更新最近颜色，不切换页面连续标注工具。新建和实际改色记录使用历史，单纯选择尚未应用的颜色不计为标记使用。

窄屏保留三个标注按钮，将导图和翻译入口收进“更多”；320pt 手机和 768pt 平板的工具栏、颜色面板通过边界检查，过长的颜色／线型横栏可横向滚动。Esc 先关闭选区的颜色面板，保留当前工具和选区。

截图均由实际 Flutter 组件导出，像素密度为 2 倍。`highlight-settings-*` 和 `underline-settings-*` 同时包含选区工具栏和对应横栏；`toolbar-*`、`highlight-palette-*` 和 `underline-palette-*` 为各组件局部。`page-toolbar-*`、`page-underline-palette-*` 验证顶部页面工具栏恢复原样。
