# GUL-626 多文档脑图验收

PR: https://github.com/mylxsw/marginmind/pull/151

## 行为与兼容

- 根据 `MindMap.generation.sources` 跟随文档切换脑图，多张关联脑图使用最近访问顺序；设置默认开启。
- 未关联文档的提示按学习集记录，关闭、执行操作或切走后不重复。
- “并入当前脑图”预选原依据和新文档，保留原章节选择，以按主题合并方式生成当前脑图的新分支。基线尚未合入批次 C，采用任务允许的回退；复用既有草稿审阅、保留及撤销。
- 多文档草稿和保存后的出处使用相同文档色点；点击出处先切文档再跳页，并保持合成脑图。
