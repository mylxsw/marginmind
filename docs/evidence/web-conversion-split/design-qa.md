## 结果

- 布局：左侧预览约占 65%，右侧为单行名称与纵向格式选项；预览最大高 600pt。窄窗改为上下布局，预览保留 300pt；矮窗预览至少 220pt，设置区域和正文分别可滚动，底部操作始终可见。
- 文案：保持“保存到资料库”“文档名称”“保存格式”“取消”“保存文档”；没有副标题和格式说明。
- 排版：沿用 SF Pro/PingFang，正文 15pt、1.75 行高，标题 20pt、分节 16pt；保留网页原有强调、分段和图片。正文不再挤在 88pt 摘要框。
- 色彩：沿用应用语义色、系统强调色及既有按钮；保持深色主次层次。生成稿的材质没有替换应用主题。
- 资产：使用现有 Lucide 图标。示例文档无图片，因此截图没有设计稿中的示意建筑照片；实现只展示网页实际捕获的图片，不向用户文档插入生成图。
- 滚动：预览的 `ScrollConfiguration` 禁止系统自动添加滚动条。实际拖动测试确认滚动位置前进且不存在 `RawScrollbar`，保留滚动能力。
- 无待修复的 P0/P1/P2 问题。原生字体、图标及真实文档内容与示意图的差别属于明确的产品适配。
