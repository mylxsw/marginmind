## 初始尺寸

| 任务 | 初始大小 | 说明 |
| --- | --- | --- |
| 完整 AI 对话、阅读导航及管理、设置、图片预览 | 安全区内最大高度 | 长内容和持续编辑，无需先上拉 |
| 卡片详情、查词、选区翻译、生词上下文 | 可用高度 75% | 内容较多，保留少量原文背景 |
| AI 快捷操作 | 可用高度 70% | 临时选段操作，完整容纳常用菜单和输入区 |
| 添加、更多、颜色预设、脑图样式、短表单、保存笔记 | 随内容高度 | 不为少量内容占用半屏 |
| 原生阅读工具等短操作 | medium，可上拉 | 平台操作容器，保留原文上下文 |

高度比例针对安全区与键盘之外的可用空间；展开保留状态栏及底部手势安全区。横屏与键盘状态采用可用最大高度，不把工具与输入挤在半屏中。

同类入口同步修复：阅读设置、脑图样式、自定义颜色回退、查词、选区翻译、生词上下文、全文翻译状态和保存笔记。它们通过 `MMModalContent` 在已有面板内只输出正文与内边距，独立桌面浮层仍有自己的外框。设置的功能分组、可编辑输入区与颜色样本保留必要边界。

只在专用测试模拟器运行，避免影响日常资料。先卸载专用模拟器中的示例应用，再执行：

```sh
PATH=/Users/mylxsw/fvm/versions/3.47.2/bin:$PATH \
  python3 tool/capture_mobile_redesign.py SIMULATOR_UDID iphone \
  --test mobile_surface_hierarchy_acceptance_test.dart \
  --output docs/evidence/mobile-surface-hierarchy-2026-11-04/iphone
```

运行通过后，在安装 Pillow 的 Python 环境中执行 `tool/build_mobile_surface_review.py`。该脚本保留系统原图，生成六张两列三行拼图与可切换深浅色的画廊；验证失败或源码变化时拒绝打包。

## 章节目录删去多余状态

本轮按用户明确要求收敛为章节名称、层级缩进和点按反馈：移除“文档开头”入口、当前位置对勾和加粗，不增加“当前”标记。仅省略与文档名重复的起点根条目，并提升其子章节显示层级；其余真实章节标题、原始目录及锚点不变。仅有文档根标题时显示正常空目录。

原生浏览、Flutter 管理 / 回退，以及 PDF 章节目录使用同一原则。PDF 目录不再随正文翻页自动展开或强调当前章节；用户手动收起的章节保持收起。Tab 的分类选中态保留，表示用户正在看目录、书签或标注。
