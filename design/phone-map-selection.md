# 手机导图选择方案

状态：已实现，自动检查及两端模拟器验收见[验收记录](../docs/evidence/phone-map-selection-2026-11-03/README.md)。适用 iPhone 和 Android；延续固定底部操作栏、统一悬浮面板和现有设计系统。

## 问题与目标

当前矩形框选只处理鼠标输入；触摸进入画布平移和缩放逻辑。“多选”实际主要改变节点逐个点选的行为，缺少稳定可见的选择状态和调整区域的入口。手机用户既需要快速圈入一片节点，也需要补选、排除和修正边界。

目标：选择与结构编辑有明确分工；允许用户松手后修正；跨屏选择时继续移动画布；选择完成前不改变节点结构。

## 入口与页面状态

导图视图工具提供带文字的“多选”入口。已有节点选中时，在底部“更多”中也提供同一个入口，无需先取消选择。

进入后显示固定状态栏“取消 · 已选 N 项 · 完成”。底部切换“点选 / 框选”，并提供“清空”；批量合并、删除、结构移动等操作在完成选择后再显示。初次进入默认点选，并以短提示介绍框选和双指移动。

进入时将当前选择复制为临时选择。节点有一致的选中描边与勾选标记；标记不再占据一个必须精准点中的小按钮。框选边界与颜色继续使用系统强调色。

## 操作规则

| 模式或操作 | 结果 |
| --- | --- |
| 点选模式：轻点节点 | 加入／移除该节点；整个节点都可以点击，扩大触控区域，密集节点按最近目标判定。 |
| 点选模式：单指滑动 | 平移画布，轻微抖动不能误选节点。 |
| 框选模式：单指拖动 | 画出矩形，实时高亮候选节点和更新数量；可从节点上开始，节点不进入结构拖动。 |
| 框选模式：松手 | 保留选择框和四角手柄，允许修正，而不是立即消失。 |
| 拖动四角 | 调整范围，手柄触控区域至少 44×44 点，视觉标记保持小而清楚。 |
| 拖动边框 | 平移整个选择框，重新计算候选节点。 |
| 在当前框外开始下一次框选 | 保留上次选择，添加新区域。 |
| 双指操作 | 平移／缩放画布；选择框跟随导图内容，所选节点不因镜头改变而改变。 |
| 拖框靠近画布边缘并停留 | 连续缓慢移动画布，便于跨屏选择，顶部与底部控制区不作为触发区域。 |
| 完成 | 提交临时选择，退出选择模式，显示已有的固定底部批量操作栏。 |
| 取消／安卓系统返回 | 恢复进入前的选择，退出选择模式；不会直接离开阅读页面。 |

## 选择与误触规则

1. 默认按节点中心进入矩形判定；框边轻擦长节点不会把它意外选中。矩形与节点高亮实时反馈，最终数量必须与高亮一致。
2. 框选只计算当前可见的内容节点；根节点、连线、来源标签和折叠后不可见的后代不自动选入。
3. 多次框选默认累加。少量排除通过点选模式轻点取消，第一版不再增加“减选”手势或第三种滑动含义。
4. 正在调整的区域，候选选择始终由“这一轮之前已选的节点 + 当前矩形”计算。缩小矩形能撤回本轮新增节点，不会误删之前几轮的选择。
5. 切换到点选时，先保留当前矩形的结果，再移除矩形；点选补充后的结果不会在下一次画框时丢失。
6. 绘制期间加入第二根手指时，取消未完成的这一笔，恢复该笔开始前的范围和选择，然后交给双指画布操作。手势取消事件遵循相同恢复规则。
7. 选择模式中暂停长按结构拖动、长按菜单、节点双击编辑和宽度拖动。完成后恢复之前定义的节点交互。
8. 选择期间保留顶部状态栏和底部模式栏；批量操作栏在完成后出现，不能再叠放一排。数量可见、控制位置稳定。

## 与上一轮节点交互的关系

普通模式仍是“轻点选中、长按拖动、更多打开菜单”；选择模式是用户主动进入的临时状态，不借用长按入口。完成以后才能长按移动所选节点，整组移动仍走现有结构与循环保护规则。

第一版优先保证点选、框选、松手修正、双指导航、累加和取消，不增加套索、三指手势或长按弹出选择菜单。

## 验收标准

- 320 点宽的窄手机、常见 iPhone/Android、横屏、深浅色都能看到取消、数量与完成；44 点手柄可操作。
- 50%、100%、200% 缩放下，框与节点判定保持一致；画布平移、缩放后选择范围仍绑定内容。
- 在节点上开始画框时，节点不移动、不编辑、不弹菜单；长按也不会意外修改结构。
- 从任意方向画框、反向调整四角、平移矩形、缩小范围、连续添加第二个框、点选排除均可预测。
- 双指打断、系统取消、安卓返回、取消按钮都保留正确的已提交选择；取消模式不留下半完成结果。
- 空框、空白点击不会清掉之前累积的节点；“清空”有明确按钮。
- 一次选择多个节点后，完成进入批量操作；撤销、合并等后续行为沿用已有业务规则。
- 用户实际执行“选一片节点 → 修正边界 → 排除一个 → 移动画布再补选 → 完成”，检查手指遮挡和状态理解，而不仅核对静态截图。
