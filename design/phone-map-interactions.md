# 手机思维导图结构调整

## 手势分工

长按节点原先会同时启动结构拖动、选中节点、打开上下文菜单；手指移动超过阈值后再把菜单关掉。节点工具栏又跟随节点位置出现，容易挡住目标节点。这次将选择、结构拖动和完整菜单分成明确的入口。

| 操作 | 结果 |
| --- | --- |
| 轻点节点 | 选中节点，底部显示带文字的编辑、子主题、同级、问助手、更多操作。根节点仅显示适用项。 |
| 点空白 | 清除选择，回到导图视图工具。 |
| 长按节点 | 原位置拾起节点并给一次触感反馈，隐藏底部操作栏，不打开菜单。 |
| 长按后移动 | 节点跟随手指原来的抓取位置；画布保持连续，靠近边缘继续自动平移。 |
| 拖到目标中间 | 高亮父节点，提示“松手移到某节点下”。 |
| 拖到目标上下边缘 | 显示同级插入线，提示“松手放在某节点前／后”。 |
| 松手 | 有效目标按预览提交；只按住没移动、无效落点、取消事件都不改结构。 |
| 点“更多” | 打开完整操作面板，仍可从面板中精确上移／下移。 |
| 双指操作 | 继续缩放、平移；两指按住时不抢占为节点拖动。 |

底部节点栏替代原导图视图工具，不叠放两排。多个节点的操作栏同样固定底部，拖动期间隐藏。编辑文字或绘制关系时使用各自对应的界面。菜单不再承担手机长按手势。

## 细节

- 触控目标最小按屏幕 44 点计算，左右增加 12 点容差；即使缩小画布也能判断父子关系与顺序。桌面仍使用原来的精确目标区域。
- 父子关系、同级插入线与最终提交共用同一个目标结果，不能把节点放入自己或后代。
- 拖动期间停止因选中节点而触发的自动定位，避免画布突然跳动；边缘自动平移继续生效。
- 新工具栏位于固定位置；将选中节点带入视野时为它预留底部空间。
- 保留单步撤销能力。iPhone 与 Android 使用相同手势含义，分别采用平台适用材质；桌面右键及平板长按菜单保持原有行为。

实现和模拟器记录见 [验收记录](../docs/evidence/phone-map-interactions-2026-11-03/README.md)。触感和手指遮挡的最终体验仍需实体设备检查。
